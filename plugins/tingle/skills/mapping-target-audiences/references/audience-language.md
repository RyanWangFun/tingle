# 触达语言：自用非自用与用户语言

> 本件是 `mapping-target-audiences` 的深读件，**人群表初稿出来后，逐个人群过一遍**。人群定出来还不够——同一个人群，用产品语言还是用户语言、用内在感受还是显性现象，拿到的人数和转化完全不同。
> 买的人和用的人不同的类目（照护类、宠物类）必读。

---

## 一、自用人群 vs 非自用人群

适用于**买的人和用的人不是同一个人**的类目：

| 人群类型 | 能感知什么 | 表达侧重 |
|---|---|---|
| **自用人群**（自己用） | 能感知内在感受 | 直接说那些内在感受 |
| **非自用人群**（家长给孩子、主人给宠物） | 只能感知**第三方可见**的变化 | **必须用显性现象触发，不能用内在感受词** |

家长感受不到孩子的内在不适，只能看到孩子揉眼、分泌物变多、视力下降。**所以针对儿童和针对成人，表达的语言与侧重点完全不同。**

**范本**：面向儿童使用场景的封面标题不写"干涩疲劳"（家长感知不到），而写"孩子总是揉眼睛揉出红血丝怎么办""这种情况该用哪种"——**要用购买者能快速识别、感同身受的场景**。

**硬动作**：人群表每一行标 `自用 / 非自用`；凡标"非自用"的，触达语言字段**禁止使用内在感受词，只能用第三方可见的显性现象**。

---

## 二、产品语言 vs 用户语言

**核心命题：同一个产品换个表达，拿到的人数完全不同。**

很多商家最大的问题，是**只会围绕产品做内容，没办法快速把产品转移成"人的语言"**。

**一个经典的转译范本**：某个只有行业内部才用的产品术语，直播间里绝大部分人根本不知道它是什么。

| 表达方式 | 内容 | 结果 |
|---|---|---|
| **产品语言** | 围绕那个术语表达 | 用户没感知，连这个词都不知道，觉得跟自己无关，不点击 |
| **用户语言** | "它能提高专注力" → 再往前一步："最近工作效率下降、多线任务处理不过来、原来一小时的事现在要三小时" | 遇到这种情况的人有共鸣；他脑子里没有产品词，但有这个处境，会点进来看怎么解决 |

**要把产品转译成人的语言：人是谁、痛点是什么、场景需求是什么**，让他先有感知；感知完才意识到"原来这个东西能解决我的问题，我需要它"，进而购买。

**为什么点击是下限、互动是上限**：用户来这个平台不是为了看广告，是为了放松、或当资料库获取有用信息。产品语言（一眼是广告的内容）用户不想看，不会点击。**点击是内容的下限**——没有点击，流量自然不好；**互动（点赞、收藏、评论）是上限**——决定这条内容上限的，是用户点进来之后愿不愿意互动。

---

## 三、品类认知决定内容能触达谁

**关键洞察：品类认知决定内容能触达谁。** 一个专业的成分词只能触达对这个词有认知的用户；没有认知的人即使有这个需求，看到也会觉得"跟我没关系"而不点击、不提供任何流量。

**沟通语言随认知层级而变**（以美白类产品的用户自述为例）：

| 用户认知层 | 怎么表达 |
|---|---|
| 会说出具体成分名的（成分认知深） | "我们是这个成分里功效最好、浓度最高的" |
| 只说"想白一点"的（基础品类认知） | "晒后／局部沉着的人要怎么解决" |
| 归因到某个生活习惯的（感受到问题、归到某个原因） | 围绕那个原因做解决方案 |

**每一个要素的结合都会变成不一样的沟通语言，每个组合背后都是一类人。**

**凌驾性纪律**：

- **不能因为"我懂、我们团队最专业"，就只围绕最专业的那个点做内容。** 对专业品类词有认知的人，可能是最精准但也最小的一撮，你拿到手就没了，增量上不去。
- 要做**人群的品类认知画分**，让产品有更宽的内容触达面。

**品类认知的四级递进**：不知道 → 知道但没用过（需要一个触发点唤起当下需求）→ 用过但没有固定选择（挖掘他不满意的点）→ 经常用且有固定品牌（转化较难，需要新场景、新触点切入）。

**三类人三种表达**（与上一条同构）：懂且信任 → 直接讲产品价值；不懂 → 先让他知道产品能干嘛；懂但不信任 → 换角度补信任。

---

## 四、先关键词，后表现形式

> **关键纪律：先找关键词，再谈表现形式。**

关键词决定内容方向、决定触达哪些精准用户。"自用分享""好物推荐""专业背书"都只是关键词下的**表现形式**，不是优先级。**用户不会去搜"自用分享"——他会搜自己的处境。**

**一个围绕核心场景做关键词衍生的范本**（以备孕相关的营养补充为例）：

| 衍生关键词 | 用户心理与内容角度 | 导向 |
|---|---|---|
| 基础场景词 | 用户已知这个品类，直接产品推荐 | 产品导向（不需要教育） |
| 高龄场景 | 这类人群更注意保养 | 教育导向（干货／痛点／信任） |
| 长期未果 | 极致痛点——先解决那个更根本的问题 | 教育导向 |
| 已确诊某种情况 | 已经就医、知道自身问题 | 教育导向 |
| 另一半的角度 | 这是两个人的事 | 教育导向 |
| 结果性担忧 | "想要健康的结果"的顾虑逻辑 | 教育导向 |

> **产品导向 vs 教育导向**：已有品类认知的人群直接做产品推荐；往前拓展的人群需要干货方法论、痛点逻辑、信任感、过来人经验。

---

## 五、同一个买点要多角度呈现

即使确定了买点，也不能只做单一表达。**同一个人身上的标签在分层，对同一个需求的着力点不同。** 四个典型角度：

| 角度 | 传达的核心 |
|---|---|
| **干货** | "遇到这个问题，可以怎么做"——小技巧、速成 |
| **科普／顾虑逻辑** | "你高低得点进来看看"，唤起重视 |
| **专业背书** | 传达信任感——你有这个场景了，我推荐的方法或产品你该信 |
| **直接产品推荐** | 针对问题直接给解决方案 |

> 用户打开搜索框，结果那么多，不会条条都点，会根据自身标签选择性点击。**这是很多公司忽略的：论证了市场需求量很大，内容效果却不高，正因为只做了单一角度的表达。**

## 六、内容类型按转化效率排序

不同内容类型 = 不同语言 = 触达不同认知层的人，转化效率由高到低：

| 内容类型 | 触达谁 | 转化效率 |
|---|---|---|
| **单品直推** | 本身对产品和品类有认知的人 | 最高 |
| **多品横向对比／合集** | 对品类词、需求词有明确概念的人，加速决策 | 高 |
| **痛点类**（含前后对比增加信任） | 痛点足够痛、愿意花钱找解决方案的人 | 高 |
| **场景类** | 通过场景触动、唤醒需求的人 | 中（离用户比前几类远） |
| **概括科普类** | 不知道某个概念、需要被市场教育的人 | 中（离用户更远） |
| **美好向往类** | 没有明确需求、被向往唤起动力的人 | 较低 |

内容形态多样是必要的（否则把自己困死），而且能用于测试——**按数据把大部分资源集中到那少数几个高效角度上。**

**一个常见的失手：美好向往类的人群精准度**。做美好向往类时常见的错误是只写向往、不写具象——人群精准度极差。正确做法是**中和**：既有美好向往提点击率，又加上来自内容树的具象关键词让人群精准。**即使做美好向往，也要嵌入具象关键词。**

---

## 七、与我有关 vs 与我无关

刷这个平台的人没有耐心，"与我无关"会立刻划走。

| 内容 | 表达 | 结果 |
|---|---|---|
| 差 | 用成分名当主语，"这个成分怎么用？用不好可就麻烦了" | 人群很窄，只有本来就认知这个成分的人才看 |
| 好 | 用处境当主语，"头发容易出油、想清爽蓬松的护发建议" | 凡有这个困扰的人都觉得与自己有关 |

我们对自家行业和产品太熟，会习惯性用功效词、内部词表达，以为周围人都懂。一旦跳出来，会发现这些词对大部分人是陌生的——**连行业里天天说的那些缩写，很多人都不知道。一定要想人群词，围绕"人"做内容。**

### 人群精准度的折损链（定泛人群时必算）

泛投一个大题材 → 其中只有一部分人真属于这个品类 → 这部分人里又只有一小部分刚好当下缺这个产品，才是有效曝光。

**人群越泛，有效曝光占比越低，必须靠绝对池子量来补**：池子做到很大的量级，那个很小的比例才是可观的精准人数。曝光只有一两千，折损下来几乎没有精准用户。

**但也不一竿子打死**：靠泛题材素材拿曝光的做法也能成立——前提是它一年拿到的曝光量级极大，再小的比例乘上去也是可观的精准人数，成本 cover 得住。**可以投大泛人群，但前提是量级足够大；否则就要让内容从源头（封面）就精准。**

**正例**：封面直接呈现一个只有目标人群才会有的具体处境，进来的用户几乎全是精准的。

---

## 八、终检：产品在内容里的不可取代性

> **核心判断：如果把内容里的产品去掉，完全不影响我看这条内容的感受，那它就是无效曝光。**

反例：泛题材内容，所有人看了都开心，但没有然后——那是"看着开心的内容"，我看但不买。

**这是定人群的终极检验**：人群和语言定对了，产品才在内容里"不可取代"；定错了（硬凹、泛人群没量级、给非自用人群用了他感知不到的词），产品就可被取代，曝光再大也无效。

---

## 九、本工序产出的字段

| 字段 | 取值 |
|---|---|
| `自用 / 非自用` | 自用 / 非自用 |
| `触达语言` | 内在感受词 / 显性现象词（**非自用只能后者**） |
| `品类认知层` | 成分认知 / 品类认知 / 功效认知 / 无认知 |
| `导向` | 产品导向（直推）/ 教育导向（干货、痛点、信任） |
| `精准度量级要求` | 精准（可小量级）/ 泛（需大量级 cover 折损） |

> **收口纪律**：每个人群定完，都要过一遍"把产品从内容里抠掉，这条内容还成不成立"。成立 = 无效曝光 = 人群或语言没定对，回炉。
