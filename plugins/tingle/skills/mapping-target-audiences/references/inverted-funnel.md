# 反漏斗：先抓核心，再向外发散

> 本件是 `mapping-target-audiences` 的深读件，**人群穷举完、要决定"先打谁、按什么顺序打"时读**。它给的是人群表里「圈层」「精准度」「优先级」三个字段的填法，以及"怎么打透第一个核心人群"。

---

## 一、为什么这个平台是反漏斗

| 平台类型 | 漏斗方向 | 逻辑 |
|---|---|---|
| **以推荐分发为主的平台** | **正漏斗（从泛到精）** | 先大曝光囊括机会人群 → 一层层往下洗（每层之间看流转率）→ 下单 → 深度 → 复购 |
| **这个平台** | **反漏斗（从精到泛）** | 因为它有**强搜索心智**，可以**先找到最核心的人群，再慢慢发散到兴趣人群、泛人群** |

这正对应产品 0→1 阶段要做的事：先找到核心人群。

**一个反复被印证的现象**：与一个体量不大的垂类内容者合作，成交效果可以是与一个体量大得多的泛类内容者合作的数倍——**这个平台的流量精准，反漏斗成立。**

---

## 二、三层人群与各自的打法

宠物、母婴这类人群变动相对小的类目最适合演示反漏斗：

| 人群层 | 是谁 | 内容打法 | 内容形式 |
|---|---|---|---|
| **核心人群** | 已经买过我的人 | 用流量或自有账号二次触达，直接讲品牌知识、新品最核心的卖点 | **非剧情**（科普式） |
| **兴趣人群** | 刚进入这个需求、不知道怎么选的人 | 干货、科普性内容 | **剧情** |
| **泛人群** | 喜欢看这类题材、但还没有需求的人 | 大曝光内容 | **剧情** |

**内容形式铁律**：**精准人群用非剧情（科普），泛人群与兴趣人群用剧情。** 以推荐分发为主的平台正好相反——那里优先触达更泛的人群。

---

## 三、破圈的四圈层排序

不要把人群框一大堆全做（没那么多时间精力），要**排序**，按"从内往外"分四个圈层：

| 圈层 | 特征 |
|---|---|
| **核心圈层** | 转化效率最高的人群 |
| **相邻圈层** | 向外拓展的第一步 |
| **拓展圈层** | 进一步向外 |
| **新领域圈层** | 最外层 |

**很多公司没意识到这个动作，于是来回都在核心圈层里转。** 核心圈层的人量有限，花一年该触达的都触达了，再加预算也出不来增量。要逐层向外：**吃透一层 → 考虑下一圈层的人是谁 → 一点一点来。**

（三层与四圈层是同一思想的不同颗粒度；人群表的 `圈层` 字段用四圈层。）

---

## 四、量大 ≠ 优先：同一圈层内的双重排序

圈层是"由内往外"，但同一圈层内还要按**精准度**和**需求量**双重排序。

**四步法里的排序**：

1. 结合产品功效，挖掘背后的需求人群（产出关键词）。
2. **先验证需求量大小，按需求量从大到小排；再按人群精准度从高到低排**：品类认知用户 → 功效认知用户 → 更下层的人群。**精准度高的人群即使量不大，但"有需求、有认知、看到就能购买"。**
3. 根据筛出来的内容点、用户、需求做内容，发到市场测试。
4. 效率好的加量，效率差的直接放弃。

**0→1 选方向的优先级判据**：不是"拍脑袋觉得我们是这样的人就往这打"，而是**先穷举（内容树）→ 再用数据验证**。**判断优先级看：哪个树枝的人和需求，市场需求量更大、且竞争更少**（需求量大但现有解决方案不多）。

- 若切入的人群在某个痛点上需求非常少，再努力也拿不到多少流量。
- 优先做"需求量大、竞争少"的方向——**用户需求背后内容的缺失，就是我们的机会。**

---

## 五、怎么打透第一个核心人群

新品上线必须**依次**解决四个问题，顺序不能乱：

1. **这个产品到底卖给谁？**
2. **我要打哪些人群？这个人群的需求量到底高不高？** 主打卖点背后的人群需求量太窄，就会出现"上线了、也找人推广了，但流量极少"。**这是上线后的第一个问题。**
3. **怎么完成新品 0→1 的测试？** 测试期围绕什么内容方向、做多少内容量、回收哪些数据维度。
4. **如何根据回收的数据完成复制？**

### 关键洞察：人在你触达时已经分层了

哪怕只是一百多个观众，看同一个产品时的标签就完全不同。三类人 + 三种表达：

| 人群类型 | 用户状态 | 应对的表达 |
|---|---|---|
| 懂产品、有品类认知 | "我懂你" | 直接讲产品价值，帮他判断要不要买 |
| 不懂这个产品 | 连它是干嘛的都不知道 | 换新表达，先让他知道这个产品能干嘛 |
| 懂产品但不信任 | 有认知、不信任 | 换角度补信任（第三方推荐、过来人背书） |

**人变了，表述语言就要跟着变**（详见 `audience-language.md`）。

### 打透的三步法

| 步 | 动作 |
|---|---|
| **一 · 判断优先级** | 穷举（内容树）→ 用数据验证；选"需求量大、竞争少"的方向 |
| **二 · 测试与回收** | 围绕选出的三个人群、三个需求，第一个月全部发出去；数据回收，判断哪些"人 + 需求"经验证更容易戳中用户（用户完成"看到 → 找你 → 买你"） |
| **三 · 复制** | 把验证有效的"人 + 需求"内容方向，在接下来的一两个月做最大化复制（内部自制或外部合作，要求里写清人是谁、需求是什么、内容往哪个方向） |

### 反例：只拿一拨人，流量必见顶

- 一个助眠类产品，始终只拿同一类人群，没有拓新，曝光数据越来越差；而同时拿两类人群的对照组数据相差很大。**只有找到新的人和新的需求，才会有新的流量。**
- 连续数月内容方向没变，搜索持续下跌（竞争度上升 + 内容同质化）。**任何内容的效率都会持续走低，必须迭代、必须不断找新人群。**

## 六、反漏斗在生命周期里的位置

| 阶段 | 核心策略 | 人群动作 |
|---|---|---|
| 上市期（0→1） | **快** | 圈定两三种核心与目标人群，用数据验证是不是理想目标人群，是就迅速放大 |
| 成长期（1→10） | **拓** | **人群反漏斗扩充**：核心 → 兴趣 → 泛，逐层渗透 |
| 成熟期（10→100） | **占** | 市占率提升 + 消费提频（见 `penetration-metrics.md`） |
| 换新期 | **新** | 产品创新或打法创新，换到新的记忆点 |

**触达频次的含义**：这个平台需要的触达次数少于以推荐分发为主的平台——说明它影响决策心智更强。**具体几次是经验值，必须用本方历史数据重建。**

**投放取舍**：**宁愿把核心目标人群洗两遍、三遍，也不愿把泛人群投一遍。**

**一个反直觉的实操印证**：某个年龄段的点击效率明显更高，但真正的核心购买力在另一个年龄段——**宁愿前端投放直接放弃点击效率高的那一段**，因为要的就是精准流量。砍掉非精准人群之后，支付转化率往往反而提升。

---

## 七、本工序产出的三个字段

| 字段 | 取值 |
|---|---|
| `圈层` | 核心 / 相邻 / 拓展 / 新领域 |
| `精准度` | 高 / 中 / 低（品类认知 > 功效认知 > 泛认知） |
| `优先级` | 由"需求量 × 竞争少 × 精准度"综合，标 1 / 2 / 3 |

> **反模式提醒**：不要因为某个人群"量大"就排第一。量大但泛、且竞争激烈，往往不如"量中等、精准、竞争少"的人群。**第一个要打透的，永远是核心圈层里离痛点最近的那个。**
