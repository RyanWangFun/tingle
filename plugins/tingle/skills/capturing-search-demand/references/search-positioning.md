# 搜索卡位

> 本件是 `capturing-search-demand` 的深读件，**走到"卡位"那一道工序时读**。装的是：搜索池为什么是中轴、坑位盘面长什么样、卡位概率由什么决定、卡什么词、单个词怎么实测、品类适不适合做、要不要买搜索广告、卡不上怎么诊断。

---

## 一、为什么搜索是链路的中轴

把整条链路想成一句话：**先有人看到内容 → 产生种草 → 产生搜索（站内搜或直接去站外搜）→ 转化**。搜索是"种草有没有真的发生"的那道验证关。

> **流量 = 搜索 UV；搜索 UV 代表种草的有效性。** 用户看完你的内容，愿意主动来找你，这才算种草成立。

所以搜索池是品牌一定要优先做的池子：

- **更精准**：用户带着明确需求而来，转化率相对最高。**曝光场域与搜索场域的转化率往往差好几倍**（具体倍数按品类实测，不套用任何示例值）。
- **周期长**：搜索场域的流量周期可以跨很久；而发现场域是大开大合，视频流更是爆得快、死得快。
- **门槛低但上限会收窄**：哪怕没有大曝光，只要有一定阅读量，从阅读到拉搜的效率就很好；但一个词从前只有你一家做、现在有几十家来抢，单日能拿的上限只会越收越窄。

> **一句话**：种草做的所有教育，都会在用户回搜这一步被验证或被浪费——**不承接，流量就被竞品抢走**，因为用户找的是"当下这个问题的解决方案"，不一定非你不可。

## 二、搜索坑位的盘面

搜索结果不是无限位，是有结构的固定坑位——**这是卡位的物理盘面**：靠前的若干位里，只有少数几个是广告位，其余都是免费位。**不同搜索词、不同类目的盘面数量不同。**

> **重要**：不要套用任何固定数字（"前十里两个广告位"之类）。**以那个词裸号实搜到的真实盘面为准。**

**规则变过，卡位前必须知道**：

1. **流量从新内容转向沉淀内容**：靠前位置分给新内容的比例被调低，权重给到了在站内停留较久的优质内容——**套版批量产的新内容机会减少，引发过关注和兴趣的优质老内容更容易卡位。**
2. **搜索展示按类目调整**，且很多关键词下已经变成商销内容和直播（平台在提高站内电商成交）。

---

## 三、卡位概率由两件事决定

卡位**不是确定性的**（不是"发了就一定卡上"），但有概率高低。

### 要素一 · 市场对这个词的内容缺失度

用一个**当天新注册的裸号**（没有任何浏览行为，避免千人千面干扰）看真实展示状态：

| 看到的现象 | 判断 |
|---|---|
| 展示的多是较早的老内容 | 市场新内容不多 → 更容易卡上前面 |
| 翻"最新"翻不到尾、一天内的内容就很多 | 内容充足、竞争激烈 → 很难卡，除非有创新型内容 |

**大前提**：市场有需求，但竞争度没那么高。

### 要素二 · 做什么样的内容更容易卡上

看这个搜索端口下内容的"核心展示形态"，用裸号搜完观察三个维度：

1. **时间**——偏最新的内容，还是较早的内容为主；
2. **互动量**——新内容几十个互动就能卡上，还是普遍很高；
3. **内容形态**——横测 / 直推 / 用户反馈视角 / 已经变成商销与直播。

## 四、卡位两步铁律：先穷举词，再筛词

> **核心纠偏：放弃"热词逻辑"。** 重点不是哪个词热，而是先解决"我的产品卖给谁"。**要的是高精准用户，转化效率才够高。**

**第一步 · 先做关键词的穷举和罗列。** 不是找热词，而是先想清楚"我这个产品要卖给谁""这个用户打开搜索框会搜什么"——可能是需求词、场景词、痛点词，先全部穷举。

**第二步 · 再做筛选和判断。** 在这些词里判断哪个竞争度低、卡位更容易、大概要做到多少量。

### 关键词其实非常多元

很多公司的关键词只有一个：**品类词**。但围绕产品，词其实非常多元：

| 关键词类型 | 说明 |
|---|---|
| 品类词 | 最直接的那个品类名 |
| 场景词 / 痛点词 | 用户遇到问题时会怎么问（"某某情况怎么办"） |
| 功效词 | 他想达到的那个结果 |
| 人群需求词 | 不同人群的具体诉求 |

把这些词全部罗列，再判断"围绕这个词背后有谁会去搜、需求是什么"。**注意**：痛点词下的用户不一定非买你这个品类不可，他可能接受任何小办法——**关键是如何在这个关键词下把产品植入进去。每多一个词，就多一个精准流量、一个新增量。**

### 关键词写给算法看，场景写给用户看

- **关键词写给算法看**：平台通过**封面和标题**识别内容的关键词，去匹配用户搜索的关键词；所以封面、标题里（评论区埋词也可以）要出现对应的搜索词，卡上的优势更大。
- **封面场景写给用户看**：算法一次给用户一屏几条内容，要让他优先点你这条。提高点击率可以在心理上叠加**权威属性、信任感、互惠感、强需求**。
  > 例如在一个需求词下，用"某个真正做这行很多年的人推荐了什么"来叠加信任感，比平铺直叙的推荐点击率高得多。

> **注意搜索量级**：若卡上去了但这个词的搜索量级不高，能拿到的用户量很窄，**需要衡量值不值得做。**

## 五、单个词怎么验：七步实测

筛词不是查热度，是**对一个候选词逐步实测**，判断"卡得上吗、要做到多少量、做什么形态"。**换任何品类都照跑。**

| 步 | 做什么动作 | 看什么、据此判断什么 |
|---|---|---|
| **① 切"最新"看更新频次** | 把搜索结果切到"最新"排序，往下拉，数**多少屏才到"一天前"的内容** | 越快到达一天前 = 单日新增内容越多 = 竞争越激烈；翻好几屏才到 = 更新慢、竞争松 |
| **② 用"品类 + 功效 + 人群"组长尾** | 在品类词后面叠功效词、人群词，组出长尾词再测 | 词越长 = 搜索量越小、但竞争也越松（同样切"最新"看屏数验证）；**拿"搜得到的量级"换"卡得上的概率"** |
| **③ 切回"综合"、用裸号看真实展示** | 切回综合页（用户真实搜索看的是综合页，卡位主要卡这里），用**当天新注册的裸号**搜 | 避开千人千面干扰，看到这个词下的真实盘面；后面三步都基于这个真实展示来读 |
| **④ 拆核心展示形态与埋词规律** | 看前排内容的主流呈现形态，以及标题怎么埋词 | 形态是横测、直推还是用户反馈视角；标题普遍埋了哪几个核心词、至少含几个 → **定自己要做的形态和埋词** |
| **⑤ 看前排基础互动量定门槛** | 看前排内容的互动量普遍在什么档 | 是"新内容几十、两三百互动就能卡上"，还是"普遍很高" → **判断这个词的卡位门槛，以及新内容有没有机会裸跑出去** |
| **⑥（可选）用投流把数据补到超过前排** | 若想更稳地卡上，用投流把这条的数据补到超过前排的基础互动量 | 把自然互动不足的差距用付费补齐，提高卡在这个页面的概率。**这是加优势，不是必做** |
| **⑦ 对齐前排正在吃的内容偏向** | 看前排"跑出来的新内容"具体偏哪种角度 | 若前排偏"用户反馈、个人视角"而不是硬广横测，就做精准的个人视角内容更容易出来 |

> **统一逻辑**：① 测竞争激烈度 → ② 用长尾换更松的竞争 → ③ 拿裸号看真盘面 → ④ 抄主流形态和埋词规律 → ⑤ 量出卡位门槛 → ⑥（可选）用投流加优势 → ⑦ 对齐当下前排在吃的内容偏向。**每一步都是实测一个具体的词，不是查热度拍脑袋。**

## 六、品类适不适合做搜索卡位

> **搜索卡位拿的是"搜索流量"。判断标准只有一个核心——用户对这个品类有没有足够的搜索需求。**

**判断方法**：在关键词规划工具里输入品类词，看两件事：

1. **用户是不是在找"推荐、怎么选"**——出现这类问法，说明用户"不知道该选谁"，适合卡；
2. **这个需求的月搜索量级有多大**——量大才值得做。

**反例**：搜索量极低的品类做卡位毫无价值——**用户对这个品类还没有需求认知**。这类品类应该往前一步，先用内容让用户**从无到有产生需求**。

**但也别只看搜索指数**：有一类"被隐藏的需求"——某个困扰的搜索指数很低，因为**很多有这个困扰的人，因为没看到解决方案，默认就忍一忍了**。这时候正确路径是：先用能大爆的内容把需求唤醒，**再在被唤醒出来的搜索词下卡位**。

## 七、要不要买搜索广告：算账

为卡位而买搜索广告，先算账，因为**搜索广告很贵**：

- **转化率高**：搜索场域的转化率明显高于曝光场域；
- **但成本也高**：搜索的单次点击成本可能是信息流的一个数量级；某些类目单次点击很贵。
- **人群差异**：会走搜索的人更看重决策、会做比对，**转化不可能是百分之百，一定有流失。**

**判断标准（按品类的决策需求，客单价是第二层考虑）**：

| 投不投 | 适用 | 理由 |
|---|---|---|
| **适合投** | 重搜索决策的高客单品类 | 客单价摆在那、搜索决策占比高 |
| **不建议投** | 平价、低决策产品 | 用高成本把人拉进来，转化率上不去，账不划算；这类更适合在曝光场域被刷到、冲动消费 |
| **看品类属性** | 有些高价品类其实不走强搜索逻辑 | 仍以曝光场域为主，看的是这个品类的搜索决策属性 |

> **日常推广的省钱姿势**：除了大促节点，建议**以信息流为主**。搜索靠前位置的广告位很少、成本极高；而信息流推广能把内容推到那些**免费位**里去，且内容还能持续做市场教育、带来用户。**用信息流的钱去抢搜索的免费位，而不是直接买搜索广告位。**

## 八、卡不上、卡位失效的诊断

| 症状 | 根因 | 解法 |
|---|---|---|
| **新内容卡不上，被自己的老内容占着** | 新内容跟老内容没区别，平台不会用你的新内容替换你自己的老内容 | 做**新形式**去抢占其他位置，而不是想用新内容把原有的顶掉 |
| **搜索页全是仿品，把你挤走** | 围绕"自己品牌词 + 产品词"写的内容太少，标题与封面直接出现品牌词、产品词的内容缺失 | 把这个板块补上、量铺上来，慢慢把仿品内容往下挤 |
| **流量骤减、占有率被抢** | 有资金实力的竞品一下进来好几家，抢同一波精准用户 | 要么砸更多钱抢人群，要么提高内容精准度、在低成本下拿更多用户；**流量不会消失，只会转移** |
| **评测类内容卡不上搜索** | 人群做得太泛 | 去看更直接的关键词下的需求角度，**按分层的人群重做** |

> **底层认知**：平台在做**动态平衡**——一旦某个玩法所有人都在用、同质化了，平台就会打击（限流、不收录、评论被吞）。**所以不存在标准答案，卡位玩法每个阶段都会迭代。** 多看那些没有品牌溢价、只能靠效率活着的商家怎么做——他们在流量获取的效率和精准度上往往极其精细。
