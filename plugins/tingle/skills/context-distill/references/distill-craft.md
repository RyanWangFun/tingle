# context-distill —— 蒸馏手艺（循环第 3 步内部的四步流水线 + 六条贯穿纪律）

本 reference 展开两样东西：

1. **四步工艺** —— 循环第 3 步"蒸馏"内部的单向流水线：并行只读抽取 → 装配忠实台账 → 逐格溯源蒸馏 → 独立评审；
2. **六条贯穿纪律** —— 压在四步工艺（及整个循环）之上、不可让步的规矩。它们是"蒸馏"区别于"随手总结"、使产物可信可复用的原因。

正例一律用占位符（`[来源簇A]` `[字段①]` `[人群层A]` `[材料X]` 等）——只示"形"，不写死任何真实客户 / 品牌 / 项目实例。

---

## 一、四步工艺（单向流水线）

### 工艺 1 · 并行只读抽取

**做什么**：把归好类的 `raw/` 材料**按来源簇切成几束**，派**多个只读抽取器并行**读取，各自产出一份 extract。

**怎么做**：
1. **切束**：按材料的来源性质分簇，如 `[产品/事实源]` `[合规/红线源]` `[人群/场景源]` `[立项/执行源]`——簇怎么分**按项目实际材料定**，不是固定四类；一簇 = 一束 = 一个抽取器。
2. **并行派发**：每束派一个**只读**抽取器（子任务 / 子 agent），互不等待、互不共享中间态；每个抽取器只拿到自己那束的材料清单 + 同一份抽取要求。
3. **抽取要求（每个抽取器同守）**：
   - **只摘录、不做判断性压缩**——把该束里可引用的正文**原文摘录**下来并标记出处（文件名 + 段落 / 字段位置），不改写、不归纳、不评价；
   - **二进制件（表格 / 演示稿 / 文档）须抽出正文内容**，非仅列文件名——表格逐 sheet 逐区块抽值、演示稿逐页抽文字、文档逐节抽正文；
   - **在线原生件**按 `raw/索引.md` 登记的对应 lark skill 现读内容（不留副本），摘录同样标记出处（标题 + 链接 / token + 位置）。
4. **落点**：每束一份 extract 文件，落 `raw/_台账/`（工序脚手架，非引用面）。

**出**：N 份 extract（N = 来源簇数），每份 = 原文摘录 + 出处标记的忠实束。

### 工艺 2 · 装配忠实台账

**做什么**：把 N 份 extract **忠实并集重排**成一份台账——蒸馏的工作底本。

**怎么做**：
1. **忠实并集**：保留原摘录文字与来源标记，**不做二次压缩、不做判断性蒸馏**——台账是"重排"，不是"再总结"。
2. **只做三种重排**：① 按下游字段 / 主题归类（同一主题的摘录归到一起）；② 同源同事实条目合并列源（同一事实在多份材料出现 → 合成一条、来源并列全挂）；③ 重复证据去重（字节级 / 语义完全重复的摘录留一条、备注来处）。
3. **立素材警示（雷区块）**：台账**开头**立一块显式清单，把蒸馏前必须钉死的判断陷阱逐条列出，供工艺 3 蒸馏时逐一绕开、供工艺 4 评审逐条核。典型雷区类型（按项目实际材料写具体条目）：
   - `[被禁话术]`：某类表述在该领域 / 平台被禁，摘录里出现过也不得进产物正文当可用表述；
   - `[归属存疑的卖点]`：某卖点在材料里归属模糊（是 `[产品A]` 的还是竞品的、是实证还是宣传语），未核实前不得当定论；
   - `[被截断 / 自相矛盾的数据]`：某数据在材料里不完整或两处口径打架，蒸馏时须标"待核"而非择一采信；
   - `[一手源内部张力]`：两份一手材料对同一事实说法不一，须并列呈现 + 标注冲突，无法自洽取舍时命中升级条件交人裁。
4. **落点**：台账一份，落 `raw/_台账/`。

**出**：一份忠实台账 = 素材警示雷区块 + 按主题归类、来源全挂的原文摘录全集。

### 工艺 3 · 逐格溯源蒸馏

**做什么**：从台账**逐格（逐字段 / 逐条目）**抽取归纳，写出产物每格的值——这一步才开始"蒸"。

**怎么做**：
1. **逐格推进**：按产物的主题 / 类别分块逐格走，每格只从台账中该主题下的摘录取材；
2. **每条紧跟具名来源**：每写一条实质内容，紧跟一个具名来源标注，指向**真实一手材料的具名段落 / 字段**（如 `（来源：[材料X]·[字段③]）`）——不指向 extract / 台账等脚手架（见纪律 6）；
3. **蒸到下游能直接用的颗粒度**：值是可直接引用的陈述（如 `[人群层A] —— 卡点：[一句具体障碍]`），不是抽象名词标签（如只写"人群洞察"四个字）；
4. **口径承接 / 限定块随条目写**：受监管 / 有口径风险的领域，条目带的限定（适用范围、禁用场景、表述口径）随条目一并写上——**限定随条目沿用、下游引用时不可剥离**；
5. **原文含被禁话术 / 极限词时，挂标带出、不改不裸搬**：若某源材料里出现被禁话术 / 极限词（最高级 / 绝对化表述，如「最…」「绝对…」「极…」「唯一…」）且它对某块是承重的，产物须把它**带原文 + 挂待核 / 口径承接标记**，如：「原文含极限词『[极限词]』，属下游合规须改写的表述，不作已核可用语」。与工艺 2 雷区块的 `[被禁话术]` 同源，三条同守：
   - **不改写 / 不删**——改写为合规表述是下游（合规 / 审稿环节）的活，本环节不装配规则层；擅自改写 = 越界 + 丢失"原文这么说了"这个事实；
   - **不裸搬当可用语**——把「[主体]是最…的 [X]」直接写进产物、像一条已核事实那样，会把合规风险对下游藏起来；
   - **挂标带出**——与「归属存疑」flag 同款：随条目挂待核 / 口径承接标记，风险显式可见。
6. **对不上料的格不硬编**：转纪律 4，标"材料不足待补"并写清补料去处。
7. **形态为「提炼件」的那一件排在最后，且不从台账蒸。** 它的料是**其余各件蒸完之后的结论**，做法是从那些结论往上提一层，写出"这个项目在做什么生意、为什么要做、受什么根本约束"。
   - **其余件未齐则本件不产**——不许拿半套件去提。
   - **每条仍要可溯源**：溯到的是「其余各件的哪几条」以及它们共同指向的那个判断，不是凭品类常识写一段。
   - **提不出来，不许编一个套上去。** 提不出共同的上位理由，**这本身就是产出**——它说明其余各件之间没有共同理由，该报出来回头看那几件（转纪律 4 标缺口，写清是哪几件对不上），而不是先给一句定性再让它去统摄。
   - **为什么排最后而不是排最前**：它逻辑上统摄其余各件，时序上却只有其余件蒸完才提得出来——**序言写在最后、放在最前**。反过来做（先由人给一段定性、再照它蒸）会让蒸馏去迎合那个预设，一句随口的定性会变成裁剪材料的标准，比没有它更糟。

**出**：认知件（每件独立成飞书文档；件内四段定序 = **结论段 → 正文各节 → 缺口 → 文末溯源附表**，每节开头一句判断、每条挂具名一手源、限定与被限定者同处、约束类另带「怎么改」）；受影响的件蒸完，同步索引（每件一行：**件名 + 链接 + 回答什么 + 什么时候读 + 状态 + 缺口**）。

### 工艺 4 · 独立评审

**做什么**：产出者**不自宣完成**——派一个**独立评审者**冷读产物，跑**三关**。**这一件不可降级**：自检、自查、"我又从头通读了一遍"都不是独立评审，顶不了这一件。

> **⚠ 三关的顺序写死，不许调换，也不许只跑其中一关。**
> **一件东西可信，不等于它可用。** 只验忠实，产出的是一份每句都真、却没人能用的东西——**这是实测过的失败**：某项目九件产物跑了 11 轮忠实全 PASS，最后整体重写。

**先读这一条，它决定下面三关怎么摆——验收表里一条机械核查项都不许有。**

**可机械判的东西会吃掉一切。** 一个便宜、可判、能出绿灯的关口摆在那里，它就会变成实际被跑的那一关，真正难判的那几关被跳过——**不是因为执行者偷懒，恰恰因为执行者会在被计分的那个维度上做到极致。**

所以：**「字数超没超」「数法有没有混进正文」「格式项齐不齐」这类，一条都不进验收。** 它们是**写的时候的要求**（归工艺 3 与六条纪律），而且**第二关会自然捕获它们**——一份塞满数法说明的产物，做真活的人根本找不到要的东西，实用测试自己就不过。

**怎么做**：

1. **独立**：评审者不是产出者本人（另起一个不带产出上下文的评审任务），只拿到：产物 + 台账 + 该件的「回答什么」+ 已知下游消费者的声明块（若有）。

2. **第一关 · 逻辑（外推测试）**——最便宜，不必懂业务，先跑它。

   > **拿三个该件没有直接写过的问题，看能不能从它的结构里推出答案。**

   - 推得出来、**且说得出推的路径** → PASS
   - 有一道只能靠答题人自己的常识补上 → **FAIL**，说明那一处的上位是**目录**不是**理由**
   - **⚠ 判的是推的路径，不是答案对不对。** 答对了但说不出「我从哪一句推出来的」——**同样 FAIL**：那是答题人自己会，不是这份产物让他会。

   **为什么这一关就够定逻辑**：枚举永远不全。产物的价值不在写了多少条，在**它没写到的那些情况、读它的人能不能自己判**。理由式结构能往上推；目录式结构只能判「未命中，放行」——**而那是无声的错**。

   **为什么排第一**：**逻辑不过关的产物，逐条溯源判得再细也白费**——结构错了，每条都真也是一堆柴不是一棵树。在最便宜的地方拦住最贵的返工。

3. **第二关 · 质量（实用测试）**——**拿一件真活，只用这一份产物，做一次。**

   **⚠ 先分清产物是哪一种性质，选错测法等于没测：**

   | 性质 | 价值在于 | 怎么测 |
   |---|---|---|
   | **供给型**（装事实、素材的件） | 拿它能干成活 | **拿一件真活做一次**，看做不做得成 |
   | **拦截型**（装约束的件：红线、各类规范说明） | **拦得住坏的** | **拿一份故意造坏的样例撞一次**，看拦不拦得住、给不给得出改法 |

   **拦截型的件，用「拿一份好料跑顺一次」验是无效的**——好料本来就没什么可拦，跑得顺只证明这一次没走岔，**不证明它拦得住任何东西**。（同一个道理见 `building-work-skill` 的判废样例闸：**跑顺了证明的是这一次没走岔，不是它拦得住什么。**）

   **三样齐才算一次有效的实用测试**：
   - **一件真活**（供给型）**或一份故意造坏的样例**（拦截型）——真活须是该项目真实发生过或即将发生的；坏样例须写明「坏在哪、该被哪一条拦下」，**每一类约束各埋一处**；
   - **只用这一份产物做出来的结果**——**不许调别的件、不许用做的人自己的知识**；
   - **这个结果为什么算过关**——判据写明。

   **做不出这个检验 ＝ 这一件没完成**，不是扣分项。

   **有已知下游消费者的**：直接让那个 skill 拿这份产物真跑一次，比另找真活更硬。

4. **第三关 · 忠实**——前两关过了才跑，因为它最贵。

   - **每条溯源属实**：抽任意若干条，按来源标注回原材料核对——真能找到、且含义一致；
   - **素材警示遵守**：台账雷区块逐条核——产物是否绕开了每个雷（无被禁话术进正文、无存疑卖点当定论、无截断数据当全量）；
   - **缺口无静默填充**：对照台账核产物——料没覆盖的地方是标了"待补"，还是被悄悄编了内容填上。

5. **任一 FAIL 回工艺 3 修**；回流**不降标准**——不许把判据放宽到刚好套住已产出的东西。
6. **派不出独立评审者时：停并报，不许自检顶替。** 「派不出」是一个**做出来的结论、不是读出来的结论**——判法只有一条：**实际去调一次子代理，以调用本身失败为准**（工具不存在、调用返回错误、环境明确拒绝执行）。**不得因为读到某条"默认不主动使用子代理""能自己做就别派"一类的偏好规则，就宣告不可用**——那类规则是默认值、不是禁令，而本工艺是明写的要求，明写的要求压默认值。**一次都没试过就说"这儿大概派不出"＝ 自行降级，不合格。** 真的调不动，就**停下来把产物摆给人**、报 `独立评审派不出（附实际发起的调用与它的失败信息），请指定评审者或明确改判`，**等人拍**——降级可以，但降级是人的决定，不是执行者的决定。

**三条护栏（防这一套自己退化回机械）**：

- **一 · 主判据永远只有这三关，不许扩成清单。** 谁要往里加条款，先答：**这一条能不能被「补个格式项」应付掉？** 能 → 它是写作要求，归工艺 3 与纪律，不进验收。
- **二 · 真活与坏样例必须是真的。** 为检验专门构造的「真活」不算数；坏样例必须是**故意造坏**的，且写明坏在哪。
- **三 · 出题的人不能是产出者。** 自己出题自己答，测的是出题水平不是产物质量。

**出**：独立评审判定记录一份，**由 `context-distill` 写到 `raw/_台账/评审判定-<YYYYMMDD>.md`**，内容 = **三关各自的判定与证据**：

- **第一关**：出的三道外推题原文 ＋ 每道的答案与**推的路径** ＋ PASS/FAIL；
- **第二关**：那件真活（或坏样例）原文 ＋ 只用本件做出来的结果 ＋ 为什么算过关；**拦截型须写明每一类约束各埋在哪一处、各被哪一条拦下**；
- **第三关**：三项抽查（溯源属实 / 素材警示遵守 / 缺口无静默填充）的结果。

它是**复核过程件、非引用面产物**——与 extract 束、忠实台账同性质，**同落 `raw/_台账/`**；交人复核时指这一份，不另存副本。

## 二、六条贯穿纪律（每步工艺都受约束，逐条是操作步骤、不是口号）

### 纪律 1 · 跨材料合成

**操作**：产物**按主题 / 类别组织**，不是原始文件的镜像。装配台账时（工艺 2）把散在多处的同一主题归到一起；蒸馏时（工艺 3）同源同事实**合并列源**、多源互证的**并列成条**。
**自查句**：产物任一块的来源标注里，出现不止一份材料 = 合成在发生；每块只对应一份文件 = 还在按文件摘抄，回工艺 2 重排。

### 纪律 2 · 每条溯源

**操作**：蒸馏时（工艺 3）每写一条实质内容，**紧跟**一个具名来源标注（`（来源：[材料X]·[位置]）`），做到"第三人拿源 + 这条产物，能按名定位、逐条比对"。溯源标注是产物的一等公民，不是可选装饰。
**出处只留最小信息**：正文里的来源标注，**只写「拿着它能回到原件那一处」所需的那点东西——文件名 ＋ 位置**。
**「我怎么知道的」不进正文**：数法（这个数怎么数出来的）、扫法、已知盲区、行号区间、计数口径、转出件掉字说明、复核实证——**一律落 `raw/_台账/`**，正文最多留一个锚点。
**为什么**：这类说明经常比它记录的那条事实还长，横在正文中间。对审计是金子，对读的人是一堵墙——**而墙后面正是他要找的东西**。

**自查句**：随机抽一条产物内容，30 秒内能按来源标注翻到原材料对应段落 = 过；翻不到 / 标注含糊（只写"来自项目材料"）= 不过。
**第二句自查**：任取一条来源标注，问「这里面有没有一个字是在讲『我是怎么知道的』」——有 = 不过，那部分搬台账。

### 纪律 3 · 不发明

**操作**：每格值必须溯回具名源材料段落；**没有源的一律不写成定论**。材料对不上的格转纪律 4 标缺口。禁止动作清单：凭品类常识补一句、按同类项目惯例填一格、把"应该是这样"写成"是这样"。
**自查句**：产物里任一句拿去问"你的源是哪段"，答不出具名段落 = 发明，删掉或转标"待补"。

### 纪律 4 · 缺则标待补

**操作**：料没覆盖到的地方**显式标注缺口**，三种标法按实情选：
- `材料不足待补`：该有但没料，写清**补料去处**（问谁 / 找哪类文件）；
- `待核`：有料但存疑（截断 / 冲突 / 归属不明），写清核什么；
- `可确无·以 [某代理指标] 替代`：**真查全所有源**后确认材料体系里没有，才可下"确无"，并给出代理口径。
**硬规矩**：不静默填充；"确无"下早了、后来发现漏检 → **诚实纠正**（改标注 + 记入缺口清单），不装没发生。

**「不替它挑」必须配「在裁定到来之前怎么办」。** 材料内部对同一件事说法不一时，并列摆出、标注冲突是对的——**但只并列然后停，不合格**。这对蒸馏者安全，对下游危险：下一个拿它干活的人（或 AI）会挑一个，然后不吭声。**每一处并列，须同时给出三种处置之一**：

| 处置 | 什么时候用 |
|---|---|
| **取其严者** | 多个口径同向、只是宽严不同（例：某要求三处分别写「20-30 秒内」「前 15 秒内」「前 200 字内」→ 取最严的那个） |
| **走防御口径** | 数值互斥、其中一个最保守且出自最权威的那一份（例：同一指标说明书写 `<1%`、内部培训写 `<0.1%` 与 `0.5%` → 一律走说明书的 `<1%`） |
| **停下问谁** | 方向相反、无法调和——写明**该问哪一方**（客户医学部 / 项目负责人 / 法务），不写成一句没有收件人的「待定」 |

### 纪律 5 · 回一手

**操作**：归集时（循环第 2 步）就把每份材料标为**一手原件**或**快照 / 前人加工件**（`raw/` 内分层 + `raw/索引.md` 标注）。前人为**别的目的**做的加工件（别的环节裁剪组织过的），执行三不一回：
- **不当我们的产物**（它是别人的输出，不是本次蒸馏的输出）；
- **不当"已满足"**（它覆盖过某主题 ≠ 本次该主题已完成）；
- **不当一手源**（溯源标注不得指向它作承重）；
- **只作交叉印证**——要用它承载的事实，**回它对应的一手原件**按当前要求重做。
**自查句**：产物任一条的来源标注若指向一份加工件，且该条无一手源并列 = 违规，回一手重蒸该条。

### 纪律 6 · 产物自解释

**操作**：产物是喂给**下游程序 / 下游 AI**（没有制造者上下文）的，蒸馏时（工艺 3）执行三条：
- **字段用自解释名**：不留内部裸码（`[码-1]` 类编号）、不留流程标签（"承重 / 已核"类工作状态词）当字段名；
- **来源指真实一手材料**：不指向 extract / 台账等中间脚手架；
- **内部映射隔离进文末**：内部代号 ↔ 自解释字段的对照、脚手架文件清单、飞书 token 等，一律收进产物**文末的溯源附表**，正文不出现；附表开头注明"此映射仅供内部对齐，读产物内容不需要它"。
**自查句**：把产物正文（不含文末附表）单独给一个无上下文的读者，每个字段名 / 每条来源他都能望文知义 = 过；有看不懂的裸码 / 内部词 = 不过。
