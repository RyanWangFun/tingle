# context-distill —— 蒸馏手艺（循环第 3 步内部的四步流水线 + 六条贯穿纪律）

本 reference 展开两样东西：

1. **四步工艺** —— 循环第 3 步"蒸馏"内部的单向流水线：并行只读抽取 → 装配忠实台账 → 逐格溯源蒸馏 → 独立评审；
2. **六条贯穿纪律** —— 压在四步工艺（及整个循环）之上、不可让步的规矩。它们是"蒸馏"区别于"随手总结"、使产物可信可复用的原因。

正例一律用占位符（`[来源簇A]` `[字段①]` `[人群层A]` `[材料X]` 等）——只示"形"，不写死任何真实客户 / 品牌 / 项目实例。

---

## 一、四步工艺（单向流水线）

### 工艺 1 · 并行只读抽取

**做什么**：把归好类的 `raw/` 材料**按来源簇切成几束**，派**多个只读抽取器并行**读取，各自产出一份 extract。

**怎么做**：
1. **切束**：按材料的来源性质分簇，如 `[产品/事实源]` `[合规/红线源]` `[人群/场景源]` `[立项/执行源]`——簇怎么分**按项目实际材料定**，不是固定四类；一簇 = 一束 = 一个抽取器。
2. **并行派发**：每束派一个**只读**抽取器（子任务 / 子 agent），互不等待、互不共享中间态；每个抽取器只拿到自己那束的材料清单 + 同一份抽取要求。
3. **抽取要求（每个抽取器同守）**：
   - **只摘录、不做判断性压缩**——把该束里可引用的正文**原文摘录**下来并标记出处（文件名 + 段落 / 字段位置），不改写、不归纳、不评价；
   - **二进制件（表格 / 演示稿 / 文档）须抽出正文内容**，非仅列文件名——表格逐 sheet 逐区块抽值、演示稿逐页抽文字、文档逐节抽正文；
   - **在线原生件**按 `raw/索引.md` 登记的对应 lark skill 现读内容（不留副本），摘录同样标记出处（标题 + 链接 / token + 位置）。
4. **落点**：每束一份 extract 文件，落 `raw/_台账/`（工序脚手架，非引用面）。

**出**：N 份 extract（N = 来源簇数），每份 = 原文摘录 + 出处标记的忠实束。

### 工艺 2 · 装配忠实台账

**做什么**：把 N 份 extract **忠实并集重排**成一份台账——蒸馏的工作底本。

**怎么做**：
1. **忠实并集**：保留原摘录文字与来源标记，**不做二次压缩、不做判断性蒸馏**——台账是"重排"，不是"再总结"。
2. **只做三种重排**：① 按下游字段 / 主题归类（同一主题的摘录归到一起）；② 同源同事实条目合并列源（同一事实在多份材料出现 → 合成一条、来源并列全挂）；③ 重复证据去重（字节级 / 语义完全重复的摘录留一条、备注来处）。
3. **立素材警示（雷区块）**：台账**开头**立一块显式清单，把蒸馏前必须钉死的判断陷阱逐条列出，供工艺 3 蒸馏时逐一绕开、供工艺 4 评审逐条核。典型雷区类型（按项目实际材料写具体条目）：
   - `[被禁话术]`：某类表述在该领域 / 平台被禁，摘录里出现过也不得进产物正文当可用表述；
   - `[归属存疑的卖点]`：某卖点在材料里归属模糊（是 `[产品A]` 的还是竞品的、是实证还是宣传语），未核实前不得当定论；
   - `[被截断 / 自相矛盾的数据]`：某数据在材料里不完整或两处口径打架，蒸馏时须标"待核"而非择一采信；
   - `[一手源内部张力]`：两份一手材料对同一事实说法不一，须并列呈现 + 标注冲突，无法自洽取舍时命中升级条件交人裁。
4. **落点**：台账一份，落 `raw/_台账/`。

**出**：一份忠实台账 = 素材警示雷区块 + 按主题归类、来源全挂的原文摘录全集。

### 工艺 3 · 逐格溯源蒸馏

**做什么**：从台账**逐格（逐字段 / 逐条目）**抽取归纳，写出产物每格的值——这一步才开始"蒸"。

**怎么做**：
1. **逐格推进**：按产物的主题 / 类别分块逐格走，每格只从台账中该主题下的摘录取材；
2. **每条紧跟具名来源**：每写一条实质内容，紧跟一个具名来源标注，指向**真实一手材料的具名段落 / 字段**（如 `（来源：[材料X]·[字段③]）`）——不指向 extract / 台账等脚手架（见纪律 6）；
3. **蒸到下游能直接用的颗粒度**：值是可直接引用的陈述（如 `[人群层A] —— 卡点：[一句具体障碍]`），不是抽象名词标签（如只写"人群洞察"四个字）；
4. **口径承接 / 限定块随条目写**：受监管 / 有口径风险的领域，条目带的限定（适用范围、禁用场景、表述口径）随条目一并写上——**限定随条目沿用、下游引用时不可剥离**；
5. **原文含被禁话术 / 极限词时，挂标带出、不改不裸搬**：若某源材料里出现被禁话术 / 极限词（最高级 / 绝对化表述，如「最…」「绝对…」「极…」「唯一…」）且它对某块是承重的，产物须把它**带原文 + 挂待核 / 口径承接标记**，如：「原文含极限词『[极限词]』，属下游合规须改写的表述，不作已核可用语」。与工艺 2 雷区块的 `[被禁话术]` 同源，三条同守：
   - **不改写 / 不删**——改写为合规表述是下游（合规 / 审稿环节）的活，本环节不装配规则层；擅自改写 = 越界 + 丢失"原文这么说了"这个事实；
   - **不裸搬当可用语**——把「[主体]是最…的 [X]」直接写进产物、像一条已核事实那样，会把合规风险对下游藏起来；
   - **挂标带出**——与「归属存疑」flag 同款：随条目挂待核 / 口径承接标记，风险显式可见。
6. **对不上料的格不硬编**：转纪律 4，标"材料不足待补"并写清补料去处。

**出**：认知件（每件独立成飞书文档、按主题分块、每条溯源、缺口显式标注、必要处带口径限定）；受影响的件蒸完，同步索引（每件一行：件名 + 链接 + 一句用途 + 状态 + 缺口）。

### 工艺 4 · 独立评审

**做什么**：产出者**不自宣完成**——派一个**独立评审者**冷读产物，拿产物级标准逐条判 PASS/FAIL。

**怎么做**：
1. **独立**：评审者不是产出者本人（另起一个不带产出上下文的评审任务），只拿到：产物 + 台账 + 产物级标准；
2. **逐条判**：拿标准（该项目这份产物的验收判据，含 SKILL.md 的 DoD **全部条目**）逐条判 PASS/FAIL，每条附证据，不整体打印象分；
3. **三项专门抽查**（逐条判之外必做）：
   - **溯源属实**：抽任意若干条，按来源标注回原材料核对——真能找到、且含义一致；
   - **素材警示遵守**：台账雷区块逐条核——产物是否绕开了每个雷（无被禁话术进正文、无存疑卖点当定论、无截断数据当全量）；
   - **缺口无静默填充**：对照台账核产物——料没覆盖的地方是标了"待补"，还是被悄悄编了内容填上。
4. **任一 FAIL 回工艺 3 修**；回流**不降标准**——不许把判据放宽到刚好套住已产出的东西。

**出**：独立评审判定记录（逐条 PASS/FAIL + 抽查结果）——它是复核包的**过程件**，随产物交人复核用，不是产物本身、不入 `raw/`。

## 二、六条贯穿纪律（每步工艺都受约束，逐条是操作步骤、不是口号）

### 纪律 1 · 跨材料合成

**操作**：产物**按主题 / 类别组织**，不是原始文件的镜像。装配台账时（工艺 2）把散在多处的同一主题归到一起；蒸馏时（工艺 3）同源同事实**合并列源**、多源互证的**并列成条**。
**自查句**：产物任一块的来源标注里，出现不止一份材料 = 合成在发生；每块只对应一份文件 = 还在按文件摘抄，回工艺 2 重排。

### 纪律 2 · 每条溯源

**操作**：蒸馏时（工艺 3）每写一条实质内容，**紧跟**一个具名来源标注（`（来源：[材料X]·[位置]）`），做到"第三人拿源 + 这条产物，能按名定位、逐条比对"。溯源标注是产物的一等公民，不是可选装饰。
**自查句**：随机抽一条产物内容，30 秒内能按来源标注翻到原材料对应段落 = 过；翻不到 / 标注含糊（只写"来自项目材料"）= 不过。

### 纪律 3 · 不发明

**操作**：每格值必须溯回具名源材料段落；**没有源的一律不写成定论**。材料对不上的格转纪律 4 标缺口。禁止动作清单：凭品类常识补一句、按同类项目惯例填一格、把"应该是这样"写成"是这样"。
**自查句**：产物里任一句拿去问"你的源是哪段"，答不出具名段落 = 发明，删掉或转标"待补"。

### 纪律 4 · 缺则标待补

**操作**：料没覆盖到的地方**显式标注缺口**，三种标法按实情选：
- `材料不足待补`：该有但没料，写清**补料去处**（问谁 / 找哪类文件）；
- `待核`：有料但存疑（截断 / 冲突 / 归属不明），写清核什么；
- `可确无·以 [某代理指标] 替代`：**真查全所有源**后确认材料体系里没有，才可下"确无"，并给出代理口径。
**硬规矩**：不静默填充；"确无"下早了、后来发现漏检 → **诚实纠正**（改标注 + 记入缺口清单），不装没发生。

### 纪律 5 · 回一手

**操作**：归集时（循环第 2 步）就把每份材料标为**一手原件**或**快照 / 前人加工件**（`raw/` 内分层 + `raw/索引.md` 标注）。前人为**别的目的**做的加工件（别的环节裁剪组织过的），执行三不一回：
- **不当我们的产物**（它是别人的输出，不是本次蒸馏的输出）；
- **不当"已满足"**（它覆盖过某主题 ≠ 本次该主题已完成）；
- **不当一手源**（溯源标注不得指向它作承重）；
- **只作交叉印证**——要用它承载的事实，**回它对应的一手原件**按当前要求重做。
**自查句**：产物任一条的来源标注若指向一份加工件，且该条无一手源并列 = 违规，回一手重蒸该条。

### 纪律 6 · 产物自解释

**操作**：产物是喂给**下游程序 / 下游 AI**（没有制造者上下文）的，蒸馏时（工艺 3）执行三条：
- **字段用自解释名**：不留内部裸码（`[码-1]` 类编号）、不留流程标签（"承重 / 已核"类工作状态词）当字段名；
- **来源指真实一手材料**：不指向 extract / 台账等中间脚手架；
- **内部映射隔离进文末**：内部代号 ↔ 自解释字段的对照、脚手架文件清单、飞书 token 等，一律收进产物**文末的溯源附表**，正文不出现；附表开头注明"此映射仅供内部对齐，读产物内容不需要它"。
**自查句**：把产物正文（不含文末附表）单独给一个无上下文的读者，每个字段名 / 每条来源他都能望文知义 = 过；有看不懂的裸码 / 内部词 = 不过。

## 三、四步工艺 × 六纪律咬合表（一眼核对）

| 工艺步 | 受哪些纪律直接约束 | 该步的红线动作 |
|---|---|---|
| 1 并行只读抽取 | 纪律5（一手分层进束） | 只摘录不压缩；二进制件抽正文非列名 |
| 2 装配忠实台账 | 纪律1（归类合并列源）、纪律4（冲突/截断进雷区块） | 不二次压缩；雷区块必立 |
| 3 逐格溯源蒸馏 | 纪律2（每条溯源）、纪律3（不发明）、纪律4（缺标待补）、纪律6（自解释） | 每条紧跟具名一手源；没源不写定论 |
| 4 独立评审 | 全部六条（逐条核） | 产出者不自宣；回流不降标准 |
