# 对标与算账

> 本件是 `decoding-client-brief` 的深读件，**只在建对标池与算账那一道工序读**。装四样：进池的三信号、费用与投入产出怎么算、时间线怎么纵向还原、从四个输入推出该走哪一档打法。
> 全件不写任何具体品牌名与具体阈值——阈值随品类、客单价、体量而变，**照抄一个数就是把别人的场景当成自己的**。

---

## 一、先找候选，再判进不进池

**怎么把候选捞出来**（三个动作，都做）：翻第三方数据工具的品类榜单，留意平时不认识、突然冒出来的名字；看店铺侧的行业数据，最近有哪些新品牌出来；在平台的关键词规划工具里输入品类词往下翻，看哪些品牌词开始有搜索量。

**被你刷到 ≠ 能当对标。** 一个候选要进池，**三个信号必须全过，缺一条就会把团队带偏**。

| 信号 | 它在证明什么 | 怎么判 | 决策含义 |
|---|---|---|---|
| **① 起盘信号** | 它是否已经在这个平台种出了心智——有人开始主动搜它 | 看它的**品牌词搜索量是否从无到有出现**。**阈值随品类定，不许写死一个绝对数**：决策成本高、人群窄的品类，很小的搜索量已经是信号；大众高频品类，同样的量根本不算起来 | 有起盘信号 = 它已经跑通"内容→搜索"这一步，打法被市场验证过；品牌词搜索量始终为零 = 它自己都还没种出心智，抄它等于抄一个尚未成立的样本 |
| **② 阶段匹配信号** | 它的成长曲线起点，和本方是不是同一个量级 | 看它**成长曲线的起点距今多久**，以及客单价、品类、定位是否与本方相近。近期才成长起来的算同量级；很久以前就起盘、或已建立稳固心智的头部，不在一个量级 | 阶段匹配 = 它当年面对的竞争环境、入驻成本、玩法选择与本方接近，它怎么走本方大概率能复刻；已建稳固心智的头部**不可对标**——接品率、合作率、预算、玩法都差一个数量级，看它反而带偏 |
| **③ 只靠这个平台的信号** | 它拿到的结果，是不是真的在这个平台做出来的 | 先看它卖货链接的**流量来源**：若主要来自品牌词搜索，说明是外部投放带来的。再到各内容平台输入这个品牌，看哪个平台的**内容量级与精细化程度**最高；若其它平台基本是无投放逻辑的零散内容，才说明它主要靠这个平台 | 只靠这个平台 = 打法落在这一个渠道里，抄过来就能用；若它其实靠别的渠道撑起结果，只学这一部分会严重高估这套打法的效率 |

**三信号的顺序有意义**：① 先确认"它种出心智了吗" → ② 再确认"它和我同量级吗" → ③ 最后确认"这结果是这个平台做出来的吗"。任何一条不过，这个品牌就不该进池。

## 二、分析什么：三个维度

**A. 投放节奏**（从它上线看到最近，看完整周期）

1. 每月投放多少内容、什么形式。
2. 各形式的占比与量级，用于估成本。
3. **头部几条的互动量占总量的比重**：占比很高说明靠极致的两三条撑起来——重点判断它有没有投流、花了多少。
4. **视频与图文各自的占比与互动**：判断这个品类里哪种形式效率更高。
5. **报备（水上）内容的占比及其互动**：判断互动是自然内容带来的还是后续投放带来的。
6. **信息流与搜索广告的流量占比**：判断它花了多少钱、玩法结构是什么。

**B. 发言身份策略**

按粉丝区间划分，看每个区间投了多少内容、产生多少互动，判断哪类身份效率更高。一个反复出现的结果：**中小粉丝区间的内容量虽少但互动很高**，产出效率足够，不必额外花高价找头部。

破圈的身份类型也从这里看出来——本品类的用户常常同时活跃在另一个看起来不相干的内容领域里，那里的身份往往效率更高。

**C. 内容方向**（要一条一条点开看）

判断哪些是商业内容、哪些是自然种草，各自互动多少 → 得出哪些内容方向的互动占比更高、重心在商业还是种草、**不同时间节点的内容方向占比怎么变**（方向的迁移轨迹往往就是它破圈的那一步）。

**内容是投放最重要的抓手，要挖的是"最大曝光点"**——什么样的内容爆的概率更高、从互动到搜索的拉动能力更强。这往往不是单一品牌能看出来的，要做多品牌探索。它常常反直觉：一个功能性产品最高效的表达方向，可能落在一个与产品功能无关的生活场景上。

## 三、算清它的账：费用与投入产出

分析的最终目的是算清对方玩法背后的**投入产出**，从而判断值不值得抄。这个平台的费用只有两块：**内容费用 + 广告费用**。

### 内容费用

| 类型 | 怎么算 |
|---|---|
| 报备（水上） | 通过平台的官方合作后台直接看到单价 |
| 水下 | 统计各粉丝区间的平均单价 → 用「该区间内容量 × 该区间平均单价」倒推，从它上线累加到现在 |

### 广告费用

1. 从前面梳理出哪些是商业内容，罗列出来。
2. 在官方合作后台找到对应账号 → 打开该条内容的后台，看**自然流量**与**总流量**。
3. **广告流量 = 总流量 − 自然流量**。
4. 看这条内容的**流量来源占比**（发现页流量基本来自信息流投放，搜索流量来自搜索广告）：
   - 信息流费用 = 广告流量 × 发现页占比 × 信息流点击成本
   - 搜索广告费用 = 广告流量 × 搜索占比 × 搜索点击成本
5. 平均点击成本向平台的类目对接人索取（他会给出本类目信息流与搜索广告的平均点击成本、互动成本）。

> **总投放费用 = 内容费用 + 广告费用。**

### 算投入产出

- **对方的销售额**：抓它从起盘到现在在各电商渠道产生的销售额，判断有没有开站内店铺（锁定站内销售额），再判断还有没有开别的电商渠道，全部加起来 = 总销售额。
- **投入产出比 = 总销售额 ÷ 该平台投放总费用。**
- **渠道占比必须看全**：某个渠道的投入产出很低，另一个渠道产出极高，几个渠道加起来才是它的真实账。只看单渠道会误判。

### 三条辩证纪律（防抄错）

1. **一定要论证**——对外分享的数据未必是当下真实情况，一律回收数据自行验证。
2. **一定要判可复制性**——这套玩法至少要对本方**七成适用**才值得抄。人力成本极低的地方可以用海量账号铺内容，人力成本高的地方复制落地性极低。
3. **信息维度要足够多**——别只看一个竞品一种玩法；要往下挖这套打法是否与它自身的产品特殊性、竞争激烈程度、切入时间点、团队能力结构强相关。

### 两个最容易漏的判断

- **只看水上动作、没看水下投入，是头号死因**：把公开的内容合作费当成全部成本，忽略背后大量投流，投入产出被严重高估，对标本身就不值得参照了。
- **要看对方的隐藏资源**：线下渠道的既有关系、上游供应链的绑定、投资方重合带来的进场便利——这些本方未必具备，却只看到了结果。

## 四、时间维度：按时间线纵向还原

分析对标**必须往前看、拉到它上线至今**，看它为什么在某个时间点数据变好、爆发之前做了什么动作。维度拉得越长，变化轨迹越清楚。

同时守一条反向纪律：**这个平台迭代很快，过久之前的案例与数据基本不适用**——用多久以前的案例做参照，要按平台当下的玩法结构判断，不照搬任何固定的时间线。

逐项还原五件：

1. **渠道叠加节奏**：不同阶段流量从哪些渠道来、用什么产品推、销售承接在哪些渠道，什么时候叠加了新渠道。
2. **活动节点**：搜索曲线突然爆发时它做了什么（代言、大额曝光资源、平台活动）——很多销量不是日常投放带来的。
3. **产品组合迭代**：它的规格与价位段怎么演进，判断什么组合动销率更高。
4. **主渠道深度下钻**：选了什么身份、有什么特点、不同阶段怎么从中尾部升级到腰头部、自播流量靠投流还是自然流。
5. **定价与佣金**：定价、规格、平均客单价、佣金结构；尤其看它怎么让不同销售渠道的产品和价格不打架。

## 五、从四个输入推出该走哪一档打法

不同品牌的典型玩法差异不是随机的，它是四个输入决定的一个**决策函数**。**先用函数推出档位**；见到的任何具体品类玩法，都只是这个函数代入不同输入后的一个实例，不是要照背的清单。

| 输入 | 取值 | 把玩法往哪一档推 |
|---|---|---|
| **① 品类决策成本** | 低（金额小、刷到就买） | **自然爆文 / 带店**：链路短，中小身份即可建立信任，不需要重背书 |
| | 高（高客单、决策周期长） | **投产驱动的组合打法 / 信任型身份**：用户会到搜索池深度比较，必须卡搜索靠前位 + 靠专业或信任型身份建立信任，不能只靠发现页爆文 |
| **② 预算量级** | 小预算 | **自然爆文**：靠人力可控的自然内容 + 少量投流，把每条爆文的复用最大化 |
| | 大预算 | **高曝光 / 信息流拉爆**：买大曝光、用投流把验证过的内容放量 |
| **③ 团队基因** | 内容强 | **自然爆文 / 高曝光**：用自制优质内容驱动，把内容基因变成优势 |
| | 投流强、内容弱 | **投产驱动**：找以投流为撬动点的对标打法，商业爆文拉爆 + 搜索卡位，投入产出达标才放量 |
| | 人力铺量强（人力成本低） | **海量铺量 / 矩阵**：靠"量足够大 + 单位成本足够低"取胜 |
| **④ 有无大促节点** | 有 | 在选定玩法上叠大促节奏：节点前提前增量、把验证过的内容放量抢占；囤货型节点人群可略不精准但要大胆放量 |
| | 无 | 按日常节奏稳定跑；非购买节点放量见效慢，不堆量 |

**函数怎么用**：四个输入不是各投一票，而是**叠加收敛**——

1. 先用**①决策成本**定大方向（短链带店 vs 重搜索信任）；
2. 再用**③团队基因**看这个方向本方跑不跑得动；跑不动就把玩法**变形成本方可行的样子**（人力贵的地方，把"人海铺量"换成"精准筛打 + 投流放大"）；
3. 再用**②预算**定放量靠自然流还是靠投流；
4. 最后用**④大促**叠节奏。

**一个快速体检**：想走高曝光档时，先用平台的关键词规划工具输入品牌词看一个月搜索量。搜索量很低 = 用户还不了解你，"先高曝光建认知再唤醒购买"这套不适合刚上线的品牌——这其实就是对输入①的一次复核：认知没起来时，别选重曝光档。

## 六、把目标拆到月，以及测试期先建基点

**拆到月**：每月要做多少互动 → 需要多少条、什么形态的内容 → 其中多少是报备 → 需要什么类型的人来做。

内容由谁产，分两种情况：本方内容能力强的，只需明确本月生产多少条、什么方向；内容靠外部的，明确选什么类型的身份、本月联系谁、内容方向是什么。

**内容必须保证多样性**：后续要拿内容做付费投放，不是每条都能放出去；有多样性才测得出哪种内容的点击率与转化率最高，到节点前才有内容抓手。同质化严重就挑不出来。

**测试期先建数据基点**：不要一上线就把预算全花完。先用一小部分预算做数据回收，验证对标打法是否有效，把这笔钱要带来的互动拆到——需要哪几个内容形态、多少条内容、合作多少什么类型的身份。回收后对比：若本方的互动转搜效率、转化率都低于对标，就倒推问题出在身份选择、内容、还是投放，调整后进入第二阶段；第一阶段爆文率高的内容复制放量，效率差的放弃。

**建基点两条要点**：

1. **优先用本方自己的历史数据，没有时再看对标**——自己做出过结果的玩法更适合自己，轻易拿别人的，团队会乱。
2. **基准线是变化的**——同一品类不同内容形态，点击率可能很低却后端转化好、跑得飞快，也可能很高却流转很差、跑不动。所以"点击率多少才能跑"没有固定答案，标准是历史经验一层层叠加出来的、可变动的。
