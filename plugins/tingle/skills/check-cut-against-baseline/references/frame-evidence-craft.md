# 取证手艺 · 怎么取到站得住的证据

> 本件是 `check-cut-against-baseline` 的随件深读件，**取证那一步之前读**。
> 它管的是**怎么取到站得住的证据**；**要核哪几项、各项的合格线在哪**一律看输入「成片规范说明」，本件不列任何一项具体要求。

## 一条证据站得住，要同时满足三样

| 要求 | 说的是 | 不满足的样子 |
|---|---|---|
| **可定位** | 指得出它在第几秒（或第几秒到第几秒） | 「产品出现得晚」——制作方不知道该动哪一段 |
| **可重取** | 换个人照这个时点重取一次，看到的是同一样东西 | 拿一张已经找不回来源时点的截图当依据 |
| **可指认** | 说得出画面上到底有什么，而不是你对它的评价 | 「这一段感觉不太合规」——不是事实，是印象 |

**三样缺一，这条判定就不该进返工清单**，改进待确认项并写明缺的是哪一样。

## 分层抽帧

### 第一层 · 通抽建总览

按固定间隔通抽一遍全片。**间隔怎么定**：取到**任何一次画面切换都落不进两帧之间的空档**为止——具体值随片子的剪辑节奏走，快切多的片子间隔要更密。定完之后自问一句：**照这个间隔，一个只停留一两秒的元素会不会整个被跳过？** 会 → 加密再抽一遍。

通抽的产出是一条时间轴总览，用来干两件事：① 看出全片的段落划分；② 定出下一层要加密的是哪几段。**通抽本身不用来下任何判定**——它的分辨率不足以判字、判色、判有无。

### 第二层 · 关键段加密到逐秒

哪几段要加密，由「成片规范说明」里那几项要求各自落在哪儿决定。至少覆盖：

- 每一个必须露出的元素，其**首次出现的前后**——首次出现是最常出错的一处，也是最容易被通抽跳过的一处；
- 每一项必须常驻的东西，其**起点**、**终点**，以及**最后一处画面**——「前面全程都有」不能证明最后一处也有；
- 出现**精准数字、排名说法、比较性说法**的段落——这几类的呈现要求通常最细；
- 需要**遮挡或替换**的对象出现的段落；
- **片尾各页**——每一页各取，不合并成一次。

### 第三层 · 变化点两头各取一帧

凡怀疑某个东西**中途变了**（出现、消失、换了样子），就在变化点前后各取一帧。**只取一帧永远说不清它是"一直如此"还是"刚刚变成这样"。**

## 动态元素：查首帧，不查代表帧

屏幕上的文字与图形常常是动态的——先是一种样子、下一秒变成另一种；先缺几个字、再补齐；先是一种颜色、再变成另一种。

**规矩只有一条：出现的第一帧与完整停留帧都要看。** 拿中间那一帧当代表，会把"最终对了"读成"一直都对"，而合格线通常压在**从第一帧起**这个条件上。

同理，**同一个元素每次出现都各查一次**。首次出现、并列出现、片尾出现，三处成立与否互不代表——已观测的原样是中段几处都合规、首次露出那一处却是另一个样子。

## 看不清的时候

**看不清不是判定，是取证没做完。** 按下列顺序处理：

1. **回原始清晰度重取同一时点**——通抽帧的分辨率通常不足以判小字。
2. **放大到能逐字辨认**再判。
3. **前后各取一帧交叉看**——一帧上糊掉的字，可能在相邻帧上是清楚的。
4. 上面三步做完仍判不准 → **落进待确认项，写明"需人工复核"及卡在哪**，不进返工清单。

**猜出来的判定与核过的判定在清单里长得一模一样**，这就是不许猜的全部理由。

**被指出误判之后**：撤回那一条，并在产出里记明撤回。不改口成"虽然是对的但仍建议调整"——换个说法坚持等于没撤回。

## 三类判不准，各有各的写法

| 判不准的是 | 写法 | 为什么不能直接判 |
|---|---|---|
| **颜色是不是标准值** | 「视觉上不是…，需按色值复核」 | 屏幕呈现的色与文件里的色值是两件事，肉眼比不了 |
| **口播说了什么** | 「可见字幕显示…」 | 抽帧取的是画面，不是音频；没听过就不能断言音频内容 |
| **字号、行距是否达标** | 「视觉上偏小，需按字号口径复核」 | 同样是须按标准值比对的东西 |

这三类**一律不写成确定的不符项**，落待确认项。

## 取证覆盖清单：怎么写才算数

取证覆盖清单是**唯一能让漏抽现形**的东西。它至少要有四样：

1. 成片**总时长**（判定时点的坐标系，也是覆盖率的分母）；
2. **通抽间隔**；
3. **加密到逐秒的是哪几段**（各段起止）；
4. 基准侧抽到了**几段口播、几处屏幕文字、几条画面说明**（或几条修改意见）。

**没有这份清单，返工清单只呈现它看见的东西**——而拿到清单的人默认全片都被核过。

## 不进产出的东西

抽帧的临时文件路径、基准文件在哪台机器上、用了什么命令、中间试了几次——**一律不写进产出**。产出里出现的只有：时点、画面上的事实、撞的是哪一项、改法。

## 收尾自查（取证做完，核对开始之前逐项核）

- [ ] 元数据取到了：时长、画幅、分辨率。
- [ ] 通抽间隔定过一次，并对着"会不会跳过只停留一两秒的元素"这一问检查过。
- [ ] 每一项要核的要求，都指得出它对应的加密段。
- [ ] 每一个必须露出的元素，首次出现处单独取过帧。
- [ ] 每一项必须常驻的东西，起点、终点、最后一处画面各取过帧。
- [ ] 片尾每一页各取过帧，未合并。
- [ ] 怀疑中途变化的地方，变化点前后各取过一帧。
- [ ] 看不清的处，已按四步走完；仍不准的已落待确认项。
- [ ] 取证覆盖清单四样齐全。

**核不过就是取证没做完，不要开始核对。**
