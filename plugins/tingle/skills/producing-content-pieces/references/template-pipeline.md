# 三模板流水线：把做内容填空题化

> 本件是 `producing-content-pieces` 的深读件，**走到"选内容类型、写正文结构"那一道工序时读**。装的是把"做内容"从靠灵感的活，变成"输入产品素材 → 穿过模板 → 输出确定结果"的填空题。

---

## 〇、核心理念：点击是下限，互动是上限

把做内容填空题化的目的：**减少每次做事时额外的思考和判断成本**。左边输入产品对应的素材，穿过一套固定流程，右边输出确定性的结果。

一条贯穿全流程的判断：

> **用户来这个平台不是为了看广告**，而是为了放松、或把它当资料库获取有用信息。如果你的内容是"产品语言"（一眼是广告的内容），用户当下不想看，就不会提供点击。

- **点击是内容的下限**：没有点击，内容的下限极低，流量自然不好。
- **互动是内容的上限**：决定上限的，是用户点进来之后愿不愿意点赞、收藏、评论。

所以一切动作的前提：**把产品转译成人的语言**，让用户先有感知、愿意点击。

---

## 一、三个模板层层递进

| 模板 | 作用 | 解决的问题 |
|---|---|---|
| **模板一：产品特性 → 人和需求场景** | 围绕产品特性，找到背后可无限衍生的用户和需求场景 | 内容的源头；不做这步，套模板时不知道填什么关键词、什么场景 |
| **模板二：平台验证过的内容模型** | 把找到的人和场景套入被验证过的内容模型 | 内容的**多样性 + 点击率** |
| **模板三：高转化正文结构** | 把正文结构填空题化（开头／中间／结尾） | 内容的**转化率** |

**最关键的原点是模板一**——所有内容为产品服务、为提高转化率服务。模板一没衍生出来，套模板时就不知道加什么关键词、什么场景素材，人会卡在这里。

> **本环节的边界**：模板一（产品 → 人和场景）在上游的定人群与挖需求环节已经产出，本流程**直接吃那张内容方向表**，从模板二开始落地。

**这套体系的组织价值**：

- **自产内容流程化**：模板一由成熟的人或上游构建，新人只做模板二、三的填空题，内容生产变简单；人员流动也不影响产出。
- **对外合作可控**：找外部合作时有对标方向，提高沟通效率，甚至直接把模板转成一份填空式要求让对方照做，提高产出确定性。

---

## 二、模板二：选内容类型

把找到的人和场景，往被验证过的内容模型上套，解决内容的多样化和点击率。**按转化效率由高到低**：

| 内容类型 | 触达谁 | 转化效率 |
|---|---|---|
| **单品直推** | 本身对产品和品类有认知的人 | 最高 |
| **多品横测／合集** | 对品类词、需求词有明确概念的人，加速决策 | 高 |
| **痛点类**（含前后对比增信） | 痛点足够痛、愿意花钱找解决方案的人 | 高 |
| **场景类** | 通过场景触动、唤醒需求的人 | 中（离用户比前几类远） |
| **概括科普类** | 不知道某个概念、需要被市场教育的人 | 中（离用户更远） |
| **美好向往类** | 没有明确需求、被向往唤起动力的人 | 较低 |

**内容形态多样化为什么必要**：不同形态拿到的人群不同——单品与横测拿"对产品词、品类词有概念"的人；痛点类拿"对品类词没概念、因为痛点才来找解决方案"的人。

**所以形态多样是必要的，否则把自己困死。** 多样化还能**测试**：对当下的公司来说，哪个方向的点击率与转化效率更高，从而把大部分精力、资金、人力集中到那少数几个高效角度上。**不是拍脑袋，而是先测试、靠市场反馈判断。**

**套模板的样本**（同一个产品，四种类型）：硬广直推（"我用过最好用的某某"）／横向对比（这个品类横评效率往往很高）／多品推荐合集（用一个"长期困扰"的身份把同样困扰的人吸引进来）／痛点类（围绕困扰的"反复性"写，最后引出产品）。

## 三、点击率 = 封面 + 标题（承接模板二）

不同内容类型，封面标题的填法不同。**封面标题里的关键词全部来自上游内容方向表里的人、场景、痛点。**

- **封面**：单品类就是产品呈现图；痛点类就是痛点场景素材。
- **标题**：对应的关键词，决定点击率。

各类内容的封面标题写法（以一个日常护理类产品为例）：

- **单品直推**：用一个覆盖面极广的身份起头 + 具体症状关键词。
- **痛点类**：直接把那个具体的困扰写成标题，越具体越好。
- **场景／人群细分**：把程度和身份写进去（"某个程度的人自救指南"）。
- **替他人购买**：用**购买者能观察到的现象**写（家长能看到的、而不是使用者自己才有的感受）。
- **前后对比**：呈现使用前后的差别，或不同用量阶段的差别。
- **科普类**：以"必知"的口吻做知识干货，替他人决策的场景里信任感更高。
- **美好向往**：**即使是美好向往，也要嵌入具象关键词。**

### 标题的中和法：向往 + 具象关键词

做美好向往类最常见的错误，是习惯性只写向往（一个笼统的美好状态），导致人群精准度极差。正确做法是**中和**——既有美好向往提高点击率，又加上具象关键词让人群更精准。

具象关键词来自上游找到的人、场景、痛点。**只有精准且说到用户心坎上，点击率才高、点进来的人群与产品匹配度才高、才能带动后端转化。**

> **数据辨别**：取对标时要看**最近发布的内容**。点赞高但不是近期的、或者是靠投流引来的，对你没有意义。**精准关键词卡得好的内容，可能互动不高但实际很好**（很少的阅读就能带来一个搜索）。**不要只盯互动和点赞数据。**

### 多品横测：建立筛选判断标准

多品横测拿到的是对产品已有明确品类词、需求词的人群，作用是加速决策。**通过不同的分类标准（按成因分、按使用者分）让用户快速对号入座。**

> 这些判断标准也来自对人的判断（模板一），否则就是随手拼图，容易被判为低质内容、降权或不推流。

## 四、模板三：高转化正文结构

正文结构是对模板二的承接——**不同封面标题吸引进来的人不同，正文必须有针对性的诉说语言。如果所有内容都用同一套固定正文模板，转化率会极低。**

### 产品语言 vs 用户语言

**核心命题：同一个产品换个表达，拿到的人数完全不同。**

一个只有行业内部才用的产品术语，绝大部分用户根本不知道它是什么。

- **产品语言**：围绕那个术语表达 → 用户没感知、连这个词都不知道，觉得跟自己无关，不点击。
- **用户语言**：把它翻译成用户的处境（"最近效率下降、原来一小时的事现在要三小时"）→ 遇到这种情况的人就有共鸣。他脑子里没有产品词，但有这个处境，会点进来看怎么解决。

所以要把产品**转译成人的语言**：人是谁、痛点是什么、场景需求是什么，让他先有感知；感知完才意识到"原来这个东西能解决我的问题，我需要它"，进而购买。

### 正文结构按"承接选题"组织

正文结构承接封面标题——**封面标题针对什么、对谁说，正文就顺着来。** 不同模板背后的正文结构不一样。

几种已被验证的正文骨架：

| 从哪种标题进来 | 正文结构填空 |
|---|---|
| 单品 + 痛点（"某个场景真的离不开它"） | 场景和痛点 → 引发这个需求的原因 → 解决方案 |
| 人群场景切入（"长期处在某个状态的人"） | 直接给解决方案 → 产品特性 → 怎么用、拿到什么结果 → 结果呈现 |
| 场景引入（先把这件事的重要性拉起来） | 引入具体产品 → 大篇幅讲产品优势 → 优势能解决哪些具象场景 → 拿到什么结果 |
| 科普类 | 先承接选题做科普 → 关联用户痛点 → 借专业角度推荐产品 |

> **解读正文结构的方法**：培养拆解能力和耐心——解读它的封面标题是写给谁看的、正文如何围绕选题表达、评论如何把用户的关注点引到产品上。

## 五、模板与要求、水下内容、数据的关系

- **有了模板怎么用**：转成给外部合作方的要求，告诉对方每个模板具体怎么做。
- **转化率看数据**：从阅读 → 拉搜 → 搜索人群进来后的转化率。若某个模板的搜索人群转化率明显低于同行，说明内容有问题（口碑或精准度），**要靠数据判断，不靠感觉。**
- **水下内容建议做**：平台虽然强调付费，但付费坑位就那么几个，靠前位置里大部分仍是免费位，很多是水下内容。**做水下时内容要往真实用户角度走**——若赤裸裸全是品牌词产品词，平台不傻；若像真实用户角度的分享，平台无法判定它一定是广告。

---

## 六、上游依赖：内容树（只回顾，不展开）

整套体系最难的是模板一——**找到产品特性背后能无限衍生的用户和需求场景**。找不到，就没有关键词、没有痛点场景词，后面的模板无法套用。

> **本环节的约定**：模板一是上游定人群与挖需求的产出，本流程**直接吃那张内容方向表**。这里只点明它的存在与重要性。
>
> **不整条照抄现有爆文**——抄会同质化，竞品也能看到，一个版式火了会被迅速抄、流量大量下跌；要做的是跳出同质化，找背后的用户、构建更多元的用户和使用场景。

内容树构建好之后，就能清晰决定"这个月主要打哪一支上的什么人、什么需求，一个角度做多少条"，并据此安排自产内容、或决定找什么样的合作方。**合作方是跟着内容策略走的**——先明确内容写给谁，才知道找什么人；很多公司把内容全权交给合作方，导致内容不可复制。
