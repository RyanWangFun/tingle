# 给出合理指标

> 本件是 `planning-campaign-and-kpi` 的深读件，**走到"给出合理指标"那一道工序时读**。装的是：怎么把一组指标**倒推**出来，而不是照搬客户拍脑袋的数。

---

## 一、凌驾性原则：指标跟着目标走，逐层推导

> **考核来源于你的目标是什么。**

完整推导链（给团队的指标、给客户的指标，都走这一条）：

```
先确定核心投放目标（闭环成交 / 站外溢出 / 种草曝光）
    → 确定这块业务由哪些人、哪些动作构成
        → 每个动作、每个岗位的职能是什么
            → 对应的才是它该考核什么、它能可控的点是什么
```

**核心命题**：所有职能，都是围绕**它能影响的核心要素**去设定考核的。一个执行动作影响不到的东西（比如内容策略），就不该设成它的指标。

**没有通用模板**。不能直接套一张固定的多维指标表给所有人，因为**不同内容形态的流转效率不一样**（硬性内容从看到搜的转化，可能是软性内容的数倍），数据基点也各不相同，不能用唯一标准要求所有动作。正确做法是：回归日常动作 → 数据回收 → 找出有效动作 → 分类 → **不同动作建不同的数据基点** → 再考核。

---

## 二、三条倒推路

### 路 A · 从可控要素倒推

按"目标 → 业务结构 → 岗位职能 → 可控要素"推导后，**只把执行动作能影响的核心要素设成它的指标**：

| 业务类型 | 第一要义（基础完成量） | 第二要义（超出部分的奖赏） |
|---|---|---|
| **闭环 · 内容即产品的品类** | 完成基础内容量（正文、封面、标题的影响相对小） | 素材拍得更好、点击率与互动率更高 → 偶发爆文 |
| **闭环 · 以投流为主** | 内容量要到一定基数，才可能出现少数几条"单日消耗过千、过万"的跑量内容 | 跑量模板的奖赏（注意是"跑量模板"，不是"爆文"） |
| **站外溢出** | 前端内容效率 + 后端流转效率；选题被框死、策略已定的情况下 | 优化正文与转化逻辑，把转化率作为核心指标 |
| **零到一起盘** | 一切未知，先有一个确定性动作——这个平台上唯一能确定的是**内容数量** | 数据回收后再定下一阶段的投产指标 |

**一个必须说清的判断**：如果内容策略层面的人群计量本身就很大，而某个执行动作没办法跑到那么大的量，**"大爆文"对它就不可取**——不能设成它的指标。它能影响的是内容完成量与转化率。**影响不到的，再怎么要求也没用。**

**考核从链路最前端卡起，不能上来就卡结果**：先看这些内容拿到多少阅读量。连阅读量都没完成，考核后面的投入产出比没有意义——第一关都没过。先解决前端，有数据往后流，才谈结果指标。

**给指标要具象**：抽象的"有效内容模板""投入产出比"对执行动作没有感觉——要拆成"主要哪三个方向、对标是什么、这周做多少条"。具象了，这件事才和它有关、它才知道怎么做。

### 路 B · 从历史、竞品、行业结果倒推

> **拒绝"我觉得"。先问：我用什么标准界定这个数？** 参照物来自三处——往期投放数据、第一次做时的政策性数据、行业与竞品数据。

用竞品数据建基点的范例（数字是示范怎么比，不是可照抄的值）：

| 维度 | 我 | 同行 | 这个差距说明什么 |
|---|---|---|---|
| 同样数量的内容带来的阅读 | 较低 | 较高 | 同行点击率高、内容效率好 → 我的"多少条带多少阅读"基点该往同行靠 |
| 阅读到搜索的折损 | 很低 | 明显更高 | 我的内容种草力差 → 这段折损率就是一个可定的指标基点 |
| 搜索到转化的转化率 | 很低 | 明显更高 | 转化环节出问题 → 转化率基点参照行业 |

> 行业数据能清晰告诉你"同行大约多少个阅读带来一个搜索""搜索转化率平均在什么水平"，你一对照自己的数，立刻知道差距和该定的目标。**这就是合理指标的来源——不是拍一个数，是拿参照物推一个数。**

### 路 C · 从销售额公式逐层降维

所有指标最终回到这条用户流转公式：

> **销售额 = 搜索 UV × 客单价 × 转化率 ×（1 + 复购率）**

链路与折损：

> **商业流量（阅读量）→ 搜索（多少人愿意来找我）→ 转化（多少人买我）**，每段之间都有折损率。

由公式与链路倒推出一组**过程指标**（比一个总销售额可落地得多）：阅读量 → 进店 UV → 进店转化 UV → 阅读成本。抓好这几个就够。

**倒推示范**：目标销售额 ÷ 转化率（产品还没运营时，看客单价相近竞品的转化率）÷ 客单价 = 需要的搜索量 → 由"多少互动带一个搜索"的竞品基点算出需要的总互动量 → 判断这些互动靠自然内容还是广告带来 → 得出预算。**这串数就是一组层层咬合、可验收的指标。**

---

## 三、两个普遍错误

很多公司在这两点上卡住，导致指标不合理：

1. **只有最终指标"销售额"，没有指标拆解**——要拆成 曝光阅读量 → 点击率 → 引流 → 转化率 → 活跃率，这些才是数据基点。
2. **只看数据，不回溯过程**——不去看影响数据的过程动作（封面标题决定选题与用户有效性、正文逻辑决定转化、评论区引导、素材场景），也不归类总结。**把这些建成标准，就是公司可直接复制的部分。**

**数据延迟提醒**：内容有流量生命周期，数据监控要延长到较长的窗口才能把内容的价值跑完（常见的情况是"最近销售涨了但没做什么动作"，回溯发现是更早发布的某条内容最近爆了）。**定指标的回收窗口别设太短。**

---

## 四、复购特性决定怎么卡

- **无复购的新品**：算单次投入产出（销售额 ÷ 获客成本），单次卡死。
- **高复购属性产品**：不要把单次投入产出卡死，**只要单次获客成本不亏就可以**，然后拼命抢流量把天花板做高。

**逻辑**：首次获客的流量成本只会越来越贵。一开始把前端口子放得太窄，后链路非常吃亏；一旦拿到愿意复购的用户，后续获客成本大降。所以要**算总账**——站外获取 + 站内结合 + 产品复购特性综合判断。

常见的两种表现：某个高复购品类实际能做到更高的单次投入产出，却主动只要求做到不亏，为的就是把总账做到最大；另一个高毛利高复购品类甚至接受单次是亏的，因为毛利和复购能把后期人群拉回来。

> **毛利与复购决定可承受的投入产出比——给指标前必须先看这两个数。**

---

## 五、不同阶段，指标不同

**阶段性原则**：新项目、新人的初始阶段一切未知，第一阶段先有一个确定性动作出去——这个平台上能确定的就是**内容数量**。先出内容才有数据回收，才能制定第二阶段（默认哪几种类型、投产率大概多少）的投产指标。

- **起盘 / 测内容阶段**：指标 = 内容数量 + 前端阅读、组件点击率、站外引流率。
- **搜索还没起来的公司**：第一目标就定成搜索量（从零到有、从有到量级），别一上来定销售额。
- **成熟期占市场**：指标 = 品类人群渗透率 / 内容渗透率 / 搜索声量占比。
- **要做类目第一的品**：考核"做到第一时获取流量的成本是否比竞品低"，而不是看站外搜索。

---

## 六、把合理指标沉淀成可复制资产

指标的最终意义不是一张填给上级的表，而是**把有结果的经验沉淀为团队资产**。

**建数据基点的示范**（示例值，非通用真值——**每个品类、每个内容形态都要按自己的历史与竞品重建**）：曝光量达到某个线以上才值得分析（用于筛出市场感兴趣的选题）、封面点击率达到某个线以上才看（符合的截图二次复用）、观看时长达到某个线才算有价值。满足这三个基点的内容不用再思考、反复复用（确定性内容），新内容只占小部分用于验证。

**复盘的目的不是填数据告知上级"我没完成"，而是得出"接下来怎么提高完成效率"**——这周完成一半，找到问题做总结，下周更高，再下周更高。

**天赋型选手要复盘成团队资产**：核心员工离职曾让营收大幅下滑。即便招到网感极高的人，也要把他"有结果的数据经验"建成基点和维度，变成团队可复用的东西。

---

## 七、本工序的落地动作

1. **锁目标与链路终点**（从上游拿），确认是闭环、外溢还是种草曝光。
2. **走三条倒推路给数值**：
   - 路 A：把目标拆到动作，只给"动作能影响的核心要素"当指标，从前端阅读卡起。
   - 路 B：用竞品、行业、往期数据给"多少条内容带多少阅读 / 折损率 / 转化率"的基点。**没有参照物就标"需先建监控，无法给确定值"，不要拍一个数。**
   - 路 C：用销售额公式把总目标拆成阅读量 / 进店 UV / 进店转化 UV / 阅读成本这一组过程指标。
3. **按复购特性定卡法**（无复购卡单次；高复购单次不亏即可、算总账）——**先看毛利和复购**。
4. **按阶段调整**（起盘先内容数量或搜索量；成熟期三渗透指标；类目第一看获取成本）。
5. **每个指标数字挂回一个定性意图**，防孤儿指标。
6. **输出**：主指标、过程指标链（含折损基点）、每个数值的来源、复购特性处理；并把"客户原始指标与这份建议的差距"交给谈判那道工序。
