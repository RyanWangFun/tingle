# 链路与人群预算的组合取舍

> 本件是 `planning-campaign-and-kpi` 的深读件，**走到"定链路与人群预算"那一道工序时读**。装的是：产品的决策成本、产品线数量、人群结构决定了链路怎么搭、预算怎么在人群层之间分。

---

## 一、总前提：先定目标，再从三处找机会点

服务方很难取代客户定目标——这笔钱想达到什么目标，要客户给方向。目标定完后，**基于市场环境和竞争，从三处找机会点**；机会点在哪，决定链路打法：

| 机会点在哪 | 对应的链路与打法 |
|---|---|
| **人群**（有人群趋势机会） | 垂直打法：垂直内容 + 垂直发言身份 + 垂直人群渗透 |
| **品类优势**（需要破圈找新人群） | 探索第二圈层 |
| **已是赛道前列、要夯实忠诚度** | 介入平台的大型商业化资源，加大曝光和美誉度（费用主要花在大型资源、头部背书、出圈活动上） |

**一个找机会点的完整示范**：一个消费电子品牌推箱包品类时，品牌本身有机会点；但品类知名度不如已经在这个平台深度渗透的既有品牌，品类上没有机会点；于是转向看产品差异化——某个联名款有颜值上的机会点，于是去渗透联名带来的人群（人群机会点）。既有品牌适合商务人群，这个联名款适合更年轻的人群，**基于人群机会点定策略**。

> **不要既要又要还要**：目标不同，对标竞品不同、打法不同、效率差异极大。先锁一个具体要完成的结果。

## 二、决策成本高低：链路取舍最关键的一刀

| | **低决策成本**（金额小、刷到就买） | **高决策成本**（高客单、耐用品、需长期使用的产品） |
|---|---|---|
| **用户路径** | 看到满意、不贵 → 直接成交，或截图到站外搜同款购买 | 决策周期长，不会刷到一条就立刻买 |
| **种草链路** | 互动 → 搜索 → 转化，快速建立 | 先搜品类词看前几十条 → 再搜"有没有不错的推荐" → 最后搜具体品牌词 |
| **卡位要求** | 一般 | **品类词卡进前几十条（甚至前几条）；品牌词下前十、前三十必须正向且都是你的内容** |
| **舆情** | 影响相对小 | 舆情差会让前面所有动作作废；竞品可以投你的品牌词搜索广告，抢在你后面的位置截流 |
| **发言身份要求** | 普通用户身份即可，不需要建立信任度 | 需要借信任型身份建立信任——全是素人的品类，用户不敢买 |

> **高决策成本产品的目标拆解也变**：要先了解搜索广告成本、信息流成本、多少互动带一个搜索、竞品近三个月的投放与核心词占比，**再重新确定目标**，然后由销售额 → 互动 → 搜索逐层拆。

**一个反直觉但反复出现的现象**：高客单、高决策成本的品类里，做得好的竞品每月投很多内容却没什么爆文，效果依然很好——因为用户一定会到搜索池里深度比较，而**搜索结果的排序不按爆文量**，只要内容卡在关键词靠前，点赞只有几十几百也能持续获取精准用户。所以这类品的链路重心在**搜索卡位**，不在追爆文。

## 三、多产品线怎么组合投放

当品牌本身是多产品线（不是打爆一个品，而是每个品都要能独当一面）时，跑出"核心大单品 + 关联辅助"的组合有三步。**三步是骨架，换任何品牌任何类目都照跑**：

| 步 | 做什么 | 怎么判 | 据此定什么 |
|---|---|---|---|
| **① 给每个品各自找机会点** | 对**每一个**品单独跑"赛道心智排名 × 使用场景 × 用户需求"三段拆解，三段都找出核心卖点 | 看每个品在平台的**品类搜索心智排名**——谁是这个品类用户认知里最成熟、基数最大的 | 平台心智最高的那个 → **候选核心大单品**（确定性最大、最该当主推）；其余列为候选辅助 |
| **② 判哪些品可以绑定** | 在候选核心与候选辅助里，逐对比较它们"想触达的核心人群是不是落在同一场景" | **核心触达人群是否在同一场景**——同场景可绑；异场景不绑 | 同场景的品组成一个组合（互相增益）；异场景的单独打，不进这个组合 |
| **③ 用组合做老带新、带破圈** | 让核心大单品带上被选中的辅助品一起投，用核心品现成的曝光与心智给辅助品引流 | 辅助品里哪些是知名度低的、或想破圈的新品 | **核心大单品带知名度低的辅助品，把新品带出破圈**——一次投放完成"主推拿量 + 新品借势"两件事 |

**骨架的统一逻辑：不是产品逻辑，是人群逻辑。** 每个品背后想触达的人群是谁、落在什么场景，才是"能不能绑、跟谁绑"的唯一判据。同一个品类（哪怕只是一个很窄的词）都能拆出多类完全不同的人群，所以确定主推和绑定时，想的永远不是产品本身，而是产品背后的人。

**一个多产品线家居品牌的落地样本**：它在家居的搜索需求排序里发现自己某一个品类的搜索心智排第一（另一个品类虽然整体搜索更大，但它当时没有对应的大单品），于是把那个品类定为核心大单品；再把这个品类按"核心触达人群同场景"拆成三款，各自人群清晰、互不打架，可作一个组合；最后用心智第一的大单品带上其余风格款一起投，知名度高的带知名度低的，把想破圈的款一并带出。它拆出来的对应关系是这样的：

| 款式 | 卖点／风格 | 对应人群 |
|---|---|---|
| 功能款 A | 解决一个具体使用痛点 | 有该痛点的人群、独居人群 |
| 风格款 B | 某种流行风格 + 功能 | 有孩家庭、追这个风格的人群 |
| 高端款 C | 极简风 + 高端材质 | 追求质感的人群、精致中产 |

**三条边界原则**：

- **新品牌别一上来就多产品线**：心智没到、精力分散。一般**超过三个在推的品就不建议这么推**——先收敛到一个核心大单品。
- **起盘阶段还在第①步之前**：先通过选品确定哪个品在这里投放效率高、建立用户认知，别急着做组合。
- **放大阶段才适合走完整三步**：已有品牌心智，才适合做多品组合 + 更多闭环。

## 四、人群预算怎么分

反漏斗 → 预算优先砸最核心的人群。**核心铁律：宁愿把核心目标人群洗两遍、三遍，也不愿把泛人群投一遍。**

落地的三条分配逻辑：

1. **先找最精准人群**：起盘第一步一定是找到最精准的人群——人群越精准转化越高，团队和决策层才有信心。很多公司一出去就撒网式投泛人群，费用全浪费。
2. **进入人群阶段后，"精准"优先于单次点击成本**：点击成本、互动成本是第一阶段看投放效率的指标；进入人群阶段后，哪怕一条内容只有一百个互动，但发布者的核心粉丝画像与我高度重合，转化会非常惊人。**不能把指标卡得太死。**
3. **砍掉非精准人群反而提转化**：常见的情况是某个年龄段点击效率很高，但真正的购买力在另一个年龄段——宁愿前端直接放弃点击效率高的那一段，要的就是精准流量。

### 营销项 vs 效果项：决定要不要把转化算进链路

- **营销项**：很清楚"来这个平台就是做营销"，帮助生意增长但不可被直接衡量，核心转化放在其他平台。
- **效果项**：希望营销即电商交易效果。**这类才做闭环与强转化链路。**

> 这条直接影响指标：营销项的指标是曝光、渗透、美誉度（挂"心智"意图），效果项才挂投入产出比与成交额。**把营销项硬考核成效果项就是脱锚**，这条会成为谈判时的论据。

## 五、竞品花了多少钱是可以算出来的

用它来反推自己该配多少预算（完整算法见 `decoding-client-brief` 的对标深读件，这里给链路视角的用法）：

> **总投放费用 = 内容费用 + 广告费用。**

- **内容费用**：报备（水上）通过平台官方合作后台直接看；水下按"各粉丝区间内容量 × 该区间平均单价"倒推累加。
- **广告费用**：`广告流量 = 总流量 − 自然流量`；再按内容的流量来源占比拆——信息流费用 = 广告流量 × 发现场景占比 × 信息流点击成本；搜索广告费用 = 广告流量 × 搜索占比 × 搜索点击成本。平均点击成本可向平台的类目对接人索取。

由此能算出竞品的投入产出比（总销售额 ÷ 该平台投放总费用），判断哪一家的打法更值得参考，再用它的链路、人群、内容配比来执行。

## 六、本工序的落地动作

1. **定决策成本档**（高／低）→ 决定链路重心：低档把"互动 → 搜索 → 转化"快速建起来；高档做搜索卡位 + 信任型身份 + 品牌词正向防截流。
2. **数在推的品**：超过三个先收敛到核心大单品 + 关联辅助；用"赛道 × 场景 × 需求"三段定单品和它对应的人群。
3. **分人群预算**：反漏斗，核心层吃大头（洗两三遍），泛人群最后；进入人群阶段后切到"精准优先于单次点击成本"。
4. **判营销项／效果项** → 决定链路里要不要算转化、指标挂什么意图。
5. **把竞品费用算出来当预算参照**，输出链路组合 + 人群预算分配百分比。
