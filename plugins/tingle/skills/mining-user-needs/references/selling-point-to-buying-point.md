# 卖点转买点：产品语言 → 用户语言

> 本件是 `mining-user-needs` 的深读件，**走到"把卖点翻译成买点"那一道工序时读**。装的是：天平模型、特性填空术、用户语言纪律、自用与非自用的表达约束、决策成本怎么倒推内容载体、敏感表述的替换逻辑。

---

## 一、天平模型：卖点 ≠ 买点

很多品牌在这个平台上投放效率差，根因只有一个：**习惯站在商家视角说"卖点"，没翻译成用户视角的"买点"。**

| 天平一端 | 天平另一端 |
|---|---|
| **产品／商家** —— 我们的卖点（产品特性） | **用户** —— 他背后的认知点（需求与语言） |

> **卖点 = 产品特性（商家端） → 转译 → 买点 = 用户是谁 + 他的需求（用户端，让用户产生购买的那个点）。**

**为什么做不好**：我们习惯把天平的重心压在自己这端，自嗨讲"我的产品多厉害"，没有转译成用户的需求和语言，天平就失衡了。你说得再厉害，用户没感知，因为那不是他的语言。

**正确动作**：以产品特性为原点，把平衡点一点点往前移，移到"用户能听懂、是用户需求"的那一侧。当用户既能看懂、又能对应到"这个东西能解决我的问题"，内容就做对了。

### 最大的认知转换：从"营销人"切回"真实用户"

让运营、操盘手、决策层以**真实用户**身份回答"你自己买这类产品怎么决策"，大家张口就来"对比、功效、成分"——这是营销人的惯性。真正要做的，是把思维从"营销人"移到"用户"，建立**对象感**：知道这个人是谁、他的需求是什么。

> 一个小范围里的人罗列出来的每一个点，放到平台的全部用户里，都代表着一类人群。**先回归用户，再谈推广。**

## 二、特性填空术

> **一句话方法**：先客观拆解产品特性 → 给每个特性做"哪些人、什么场景、什么需求"的填空 → 把人和需求转译成关键词，嵌进封面和标题。**每多一个新买点，就多一个新人群，就多一个新增量。**

### 范本一 · 一种多用途食用油

**第一步，客观拆产品特性（不讲用户语言）**：

| 产品特性 | 成因（活性成分或机制） |
|---|---|
| 代谢性 | 含某类脂肪酸，快速转化成能量而非储存 |
| 抗菌性 | 含某种酸，可用于口腔场景 |
| 保湿修复 | —— |
| 油脂溶解性 | —— |

**第二步，做填空，每个特性衍生买点**：

| 产品特性（卖点） | 衍生买点（人 + 需求 + 场景） |
|---|---|
| 代谢性 | 减脂的人；为健康做凉拌菜的人；有明确减重目标的人 |
| 抗菌性 | 面部粉刺（青春期）；皮肤湿疹（婴幼儿／夏季易发／成人）；口腔相关困扰 |
| 保湿修复 | 秋冬皮肤干燥起皮；头发干枯毛躁；面部与身体护理 |
| 油脂溶解性 | 卸妆；家庭清洁死角 |

同一罐油就衍生出减脂餐、皮肤救急、口腔护理、护发、卸妆、清洁等大量内容方向。

### 范本二 · 一种关节营养补充剂

| 产品特性 | 衍生买点（人群／场景／痛点） |
|---|---|
| 缓解运动磨损 | 跑步、爬山、深蹲、爬楼、长距离骑行的人；大体重减重人群 |
| 延缓退化 | 中老年人；办公室久坐（关节用得太少） |
| 缓解疼痛 | 膝盖在特定天气不适；腰颈不适；长期打字导致的手部不适 |
| 预防磨损 | 养生人群；给父母买的送礼场景 |

**对应的真实内容方向**：从减脂角度切入的护关节内容、从健身角度切入的内容、从送父母角度切入的内容、从跑步角度切入的内容。

> **核心**：每个内容、每个关键词，触达的都是特定人群。不属于这个场景的人不会点这类内容——**这正是精准的体现**。封面、关键词、场景、痛点表述共同把对的人圈进来。

### 范本三 · 功效逐条映射成买点

| 产品功效 | 对应的用户需求（买点／内容方向） |
|---|---|
| 促进生长发育、支持骨骼健康 | 长高 |
| 增强免疫、促进愈合 | 伤口难愈合 |
| 参与脂肪代谢 | 减脂 |
| 保护神经系统、缓解焦虑 | 注意力与情绪相关的困扰 |

> "用户需求下的卖点提炼"，就是从产品卖点变成用户买点的过程。

## 三、用户语言纪律

### 铁律：产品词与专业词激不起警觉

一个专业的成分名，连这个平台的深度用户都大量不知道。我们习惯用自己熟悉的产品词，但用户往往不熟悉。**一旦想破圈、想被更多人看到，就不能站在自我角度表达**——还围绕那个成分名硬写，用户不懂就不点击 → 没流量 → 没种草 → 没销量。

- **用专业词描述需求是反模式**（如把用户的处境写成一个医学名词）。要用他自己会说的话（"换季一到就停不下来"）。
- **品类认知决定内容能触达谁**：专业词只触达对这个词有认知的人；没认知的人即使有这个需求，看到也觉得"跟我没关系"，不点击、不提供任何流量。
- **按认知层分沟通语言**：会说出具体成分名的（专研层）→ 沟通"我们这个成分浓度最高"；只说"想改善一点"的（基础品类认知层）→ 沟通"这种情况该怎么解决"；已经归因到某个生活习惯的 → 围绕那个原因做方案。**每个组合背后都是一类人。**

### 先关键词，后表现形式

> **关键纪律：先找关键词，再谈表现形式。**

关键词决定内容方向、决定触达哪些精准用户。"自用分享""好物推荐""专业背书"都只是关键词下的**表现形式**，不是优先级。**用户不会去搜"自用分享"，他会搜自己的处境。**

**围绕一个核心场景往下衍生子人群的范本**：

| 衍生关键词 | 用户心理／内容角度 |
|---|---|
| 基础场景词 | 产品导向（已有认知，直接推荐） |
| 特殊人群的同一场景 | 这类人更注意，往需求前一层拓展 |
| 长期未果 | 极致痛点——先解决那个更根本的问题 |
| 已确诊某种情况 | 已就医、知道自身问题，明确问题导向 |
| 另一半的角度 | 这件事不是一个人的事 |
| 结果性担忧 | "想要一个好结果"的顾虑逻辑 |
| 下一阶段的场景 | 已进入下一阶段人群的需求 |

> **产品导向 vs 教育导向**：已有认知的人群直接产品推荐；往前拓展的人群需要干货方法论、痛点逻辑、信任感、过来人经验。**跨人群的模板可复用**——两个相邻人群的模板往往相通，换个场景换个词即可。

## 四、自用 vs 非自用：表达约束不同

| 类型 | 能感知什么 | 表达侧重 |
|---|---|---|
| **自用** | 内在感受 | 直接说那些内在感受 |
| **非自用**（家长给孩子、主人给宠物） | 只能感知**第三方可见**的变化 | **必须用显性现象触发，不能用内在感受词** |

**非自用要做到"显性可见 + 代入感"**：

- **给父母买的场景**：父母的症状我们不在身边、感受不到，内容必须让**子女有代入感**——从一个子女能观察到的外部特征说起，让他对照"好像和我父母差不多"，产生"宁可买给他以防万一"的动机。
- **家长决策链要层层还原**：孩子出现某个表现 → 就医得到一个说法 → 第一方案有明显缺点 → 才去找替代品。家长的决策因素是层层叠加的：资质与安全感（首要）→ 使用是否方便 → **孩子愿不愿意接受**（再营养，孩子不接受也没用）。否则你只会说"孩子有这个问题就用这个"——用户搜那个词有海量内容，**他凭什么非买你？**
- **购买者与使用者不同的品类**，痛点感知靠"现状"：使用者的状态导致了哪些看得见的场景，找到那个人和那个具体问题去表达。

## 五、决策成本倒推内容载体

不同品类的用户决策逻辑不同，倒推出不同的内容载体：

| 品类类型 | 用户决策逻辑 | 内容载体 |
|---|---|---|
| **低决策成本**（金额小） | "买的就这一份"，不行也没什么损失，没有强购买顾虑 | 自有账号自制内容 + 素人分发即可 |
| **高决策成本**（金额高，或买给孩子、宠物这类替他人决策的场景） | 脑子已被众多品牌教育，走的是品牌决策逻辑；会极细地判断是不是被收智商税 | 需要垂类专业身份或可背书的身份——照护类信任领域内公认的专业身份，健康类信任有专业资质的身份 |

**"打消购买顾虑"的本质**：回归"用户对这个品类是怎么做决策的"。**决策方式倒推出最适合的内容载体。**

**用户决策路径决定内容布局的深度**：用户被触达后，是看完直接买？还是会打开搜索去查？查的是产品词、品类词（说明你只种草了品类）还是品牌词（说明你种草了品牌）？**这由品类的决策成本决定。**

## 六、敏感表述的替换逻辑

- 不能直接说的词，可以用**可视的呈现**替代——用状态图、尺码变化、身形对比来表达，而不是直接写那个词。
- 功效词与症状词不能随便提；**有相应资质的才可以提到对应程度**——**要打某个功效，就要做相对应的资质与指导。**

> **最大的问题不是词本身，而是脑子里没有"从产品出发能稳定围绕哪些方向表达"的框架。** 有了框架，换一个说法只是换个词；没有框架，换一个词就不知道该说什么了。
