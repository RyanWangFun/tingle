# 从人群裂变出需求与痛点

> 本件是 `mining-user-needs` 的深读件，**走到"从人群裂变需求"那一道工序时读**。装的是：裂变路径、抽象功能的处理、决策维度模型、搜索池与曝光池、需求量验证、以及内容为什么会衰减。

---

## 一、底层命题：内容做的是解决方案，不是产品

在这个平台做内容，本质不是围绕产品词展开，而是围绕**用户需求**——找到这个产品可以成为哪些人的解决方案。

> **挖掘用户需求，是促进销售转化的第一步。**

为什么？因为用户在这里的购买路径是：**发现内容先于发现商品**。大部分用户把它当内容社区、当查资料的地方用，不是当电商渠道用。**用户找的不是产品，是内容、是解决方案。**

不建立这个逻辑，只是把产品卖点写成要求丢出去分发，效率不会高——你不知道好内容的可复制方向、不知道怎么迭代、不知道有没有触达最精准的人。

**种草 = 他有问题，你有解法，满足了需求才叫种草；只摆产品 = 产品展示，不是种草。**

---

## 二、裂变路径

### 总路径

> **产品（原点）→ 产品功能 → 这个功能能服务哪些人群 → 这些人群的需求与场景 → 用什么内容跟他们沟通。**

一句话：先想这东西能干什么（既有功能），再想用户为什么买它（功能 + 他的现状），最后反推"用什么内容跟他沟通"。

### 找新需求必须从产品功效出发

人群与产品功效的"搭边度"不高时，即使做出大爆文，转化率也低。

> 销售额 = 流量 × 转化率 × 客单价。**转化率持续走低，流量增加也不一定带来销售增长。**

**卖点转买点做不好的根因，往往在第一步**——产品背后面向的人到底是谁没找准。人群找不准 → 不知道这波人的需求 → 无法围绕需求做内容 → 转化不成买点。

### 从产品的"初始设定"层层筛

产品做出来时一定有初始设定（目标人群、优势点），不会无缘无故。

1. 从**原点**（初始设定的那几个人群）开始。
2. 一个个看：这个人群"买我的理由"成不成立、使用场景和不和谐。
3. 层层筛，筛出成立的那几个。
4. **判断"抽离放大"是否合理**——合理就能做。

### 裂变范本

| 产品类型 | 裂变出的方向（节选） |
|---|---|
| 儿童益智类 | 家长买／孩子自己要 → 功能性（能力培养、亲子关系）+ 非功能性（送礼：给亲友家孩子、某个年龄段的生日、节日礼物）→ 一个品裂出七个以上方向 |
| 调理类 | 先分人：年轻人（体检异常、体型偏胖）／长辈（有慢性指标问题）→ 同一批人再用不同症状场景框出（久坐不动、加班之后、饭后） |
| 传统滋补类 | 大需求里切细分：调理 → 周期不适、手脚发凉；再细分 → 产后、补铁养发、指甲变薄 |
| 氨基酸类补充剂 | 功效逐条翻成需求：促生长 → 长高；促愈合 → 伤口难愈；助代谢 → 减脂；护神经 → 注意力困扰 |
| 矿物质类补充剂 | 已知成分名的人 → 怎么选；自制力差的人 → 提高专注该吃什么；有相应困扰孩子的家长 → 那个困扰的解决方案 |

### 多功能产品的两步法：套用户决策维度模型

把用户购买决策的所有考量，归纳为固定维度。**所有维度背后都是"用户"这一个角度。**

| 维度 | 含义 | 可填充的分层 |
|---|---|---|
| **品类力** | 用户在不在意品牌 | 不在意（满足需求即可）／必须是品牌 |
| **价格偏好** | 这个品类愿意付的客单价区间 | 高 / 中 / 低 |
| **品类认知** | 对品类的认知深度 | 不知道功效词 → 知道品类词 → 知道成分词 |
| **品牌偏好** | 是否需要二次搜品牌词背书 | 国际大牌／国内品牌／小众／白牌 |
| **人的基础特征** | 用户对自己有明确判断的固有属性 | 肤色、肤质、身体状态 |
| **人的变化维度** | 让他从"不想买"变"想买"的那个变化 | 状态变化、年龄变化、季节变化、外部目的性事件 |

**用法**：每个维度下穷举一二三四，然后做**交叉组合**——不同维度的点交叉，每个组合 = 一类具象人群 + 需求 + 场景 = 一个独立的内容角度。

**两步法（针对多功能产品）**：第一步围绕产品**找特性**；第二步把每条特性**套回这个维度框架**，看它有哪些维度、哪些需求。功能单一的产品只能从单一维度内部造内容；功能多元的产品，每个功能套一遍就有无数方向。同一个功效还能按年龄纵向拆——**同一功效、不同年龄 = 不同需求**。

**同一个人也可能同时是三类用户**：同一个大需求下，因为具体场景不同，价格偏好、品牌偏好、沟通语言可以完全不同。

## 三、抽象功能必须"先穷举症状，再反推人群"

| 特性性质 | 穷举顺序 | 实例 |
|---|---|---|
| 功能直接对应人群 | 直接穷举人群 | 长时间处在某个状态的人、某个职业习惯的人、某个年龄段的人 |
| 抽象功能（如"抗菌""调理"） | **先穷举症状与痛点，再由症状反推人群与场景** | 先列出这个功能对应的一串具体症状 → 再由每个症状反推谁会有 |

**理由**：症状与痛点会引发用户的**警觉性**，让他觉得"我有一个具象问题要解决"。陌生的产品词、专业词激不起这种警觉。

**落表三列**：人群 / 症状或痛点 / 导致原因。

> 一个人身上往往有多个需求与场景——逐个挂上去，不要只留一个。

## 四、验证需求量

### 四步法

1. 结合产品功效，挖出背后的需求人群（产出关键词）。
2. **验证需求量大小**，按需求量从大到小排；再按**人群精准度从高到低**排：品类认知用户 → 功效认知用户 → 更下层人群。**精准度高的人群即使量不大，但"有需求、有认知、看到就能买"。**
3. 根据筛出的内容点、用户、需求做内容，发到市场测试。
4. **效率好的加量，效率差的直接放弃。**

### 工具与红利公式

工具类型：第三方内容数据工具、平台的官方合作后台、平台投放后台的关键词规划工具。

- **浏览量** = 用户对该词或该场景的市场需求度。
- **该场景下的内容量** = 供给。
- **需求量大 ÷ 内容量小 = 红利机会**：把这个关键词不停嵌进内容，让搜这个词的人更容易看到你、点击你。
- **互动量** = 用户对该内容方向的认可度。

> 用工具和数据验证，是为了**降低试错成本**。临近大节点时没有那么多费用、人力、时间去试错，先验证再投放是最快的方式。

### 搜索池 vs 曝光池：每条需求都要二次拆进两个端口

| 端口 | 装什么 | 逻辑 |
|---|---|---|
| **搜索池** | 用户脑子里已有、会主动搜的词 | 关键词逻辑 |
| **曝光池** | 用户没在搜、但会被场景或痛点击中的内容 | 场景与痛点逻辑 |

**两个端口都要布局**——平台会动态平衡，不会让单一玩法持续有效；流量不消失只转移，只押一个端口会被切。曾有公司只做搜索，某年流量大跌。

> 反过来说，**搜索是沉淀**：哪怕今天只发几条、自然流很小，大部分流量仍来自历史内容带来的搜索——搜索流量的稳定性可控。爆了是幸运，没爆心态平和。**要的是精准流量，不是泛流量。**

## 五、内容会持续衰减，所以要迭代、放大、跨类目复制

### 任何内容的效率都会走低

连续几个月内容方向没变，搜索却持续下跌。两个原因：① **竞争度**（竞品来抢）；② **内容同质化**（找到高效内容要快速极致复制，否则被抢；需求人群的体量有限，同质化一严重效率就走低）。

> 由此对所有公司提出一个新要求：**建立用户洞察、持续迭代内容。能带搜索、带量的好内容，生命周期越来越短。**

### 同质化的根因与破解

**为什么同质化**：习惯性不看人、不分析背后的人，直接抄市面上现有的表达，每次抄的都是同一个维度的点。

**破解**：用维度框架往**上拎一层**抽象出维度，再往下延展。某个品类市场上只打一个具体场景，但那个场景的上位维度可能是"安全"——围绕"安全"能构建出十条完全不同的内容。

### 拉高生意上限的两条路

1. **顺着需求做产品开发**：围绕有增量的市场点多开几个产品。
2. **跨类目复制内容**：人群和需求相同时可以跨类目抄作业——某个功效在护肤品类里的讲法，可以跨到食补品类；某个困扰在一个成分品类里的内容，可以借到另一个成分品类。**这是降维打击，能跳出"总抄同行"的同质化。**

> **核心洞察**：用户不在意产品，只在意"什么产品能解决我当下的问题"。家长找一个困扰的解决方案时，好几个完全不同的品类他都可能买——**顺着用户需求走，就能获得更多商业机会。**

### 市场永远有机会

用户永远在"新手村"、永远不被满足：哪怕道理人人都懂，每次看到一个更具体的解法还是会再买一次。**无论哪个赛道都有机会，用户永远有不被满足的点（显性或隐性），挖出来就能持续走下去。**

## 六、反模式

- **脑子里只有一个人群**：团队写十条全针对同一个人，量上来了曝光和效率上不去。**大部分公司的问题出在内容上，不在投流。**
- **硬凹用户**：用户没需求，凹得再硬也不要；顺着人群、顺着需求走。
- **产品在内容里"可取代" = 无效曝光**：把突兀植入的产品去掉、完全不影响观看，就是无效曝光——说明没真正挂在用户需求上。
- **只押一个流量端口**。
- **因为自己专业，只打最专业的那个点**：对专业词有认知的人是最精准但也最小的一撮，拿完就没增量。要做人群的品类认知画分，让产品有更宽的触达面。
- **盯着竞品抄内容**：竞品也未必盯了最多的人群，它有些内容曝光高但没带转化，你抄了反而数据差。**即便盯，也要往下挖到用户需求那一层。**
