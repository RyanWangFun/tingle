# configuring-media-buying

## 概述

一句话职责：**产出一份投放方案，并让它持续跑在效率线上。**

- **内容是唯一抓手，投放只是放大器**：跑不出去先怀疑素材。"要不要投流"是个伪命题——**先把内容做对**。
- **投放找模型靠点击率，放量靠定向加出价**：两个阶段的核心要素不同，混着调必然乱。
- **先跑出模型再放量**：没有一个合格的样本模型就直接放量，钱只是花了没有反馈。

## 何时用 / 何时不用

**何时用**：成片与策划就绪，要出投放方案；投放已开跑，要排节奏、分预算、处理成本波动或数据下滑；要判断一个计划该救还是该停；要判断某个平台放大器要不要叠。

**何时不用**：
- 要造内容本身——那是上游环节，本环节吃它的产出。
- 要做搜索卡位与承接、做卖货转化、做复盘归因——各归各的环节。**本环节决定内容怎么被放大，不负责流量来了之后接不接得住。**

## 运行前

**第一步跑 `tingle check configuring-media-buying`**，拿到开工单再开工；拿到卡点单本次不跑，按卡点单载入 REQUIRED SUB-SKILL: `tingle:project-readiness` 修完复验。开工单上附着的就绪判据由本 skill 开跑时逐条对照判，判不准停下问人。

## 业务方法

四道工序。**一、二是任何成片要投都要走的主干；三在"想叠平台资源"时才跑；四在投放开跑后全程持续跑。**

### 工序一 · 定目的、选工具、定出价、跑 MVP

**投放只需要先想清两步：明确目的（拿流量还是卖货）、跑出一个能用的模型。**

**放量链条是环环相扣的**：点击率（由封面标题决定）→ 互动率（由内容质量与评论区决定）→ 组件点击率（由内容种草力决定）→ 转化（由种草力与产品购买力决定）。**核心要素是点击率**——没有点击，用户根本没看进来，后面全部不成立。

**禁止**：

- **禁止在跑出 MVP 之前放量。** 卖货要先算清投入产出比多少这个模型才成立，且要出足够单量才算数，不能凭一单；拿流量要先设一个阅读量级的标准，只有小几百的阅读看不出任何外溢。
- **禁止用小额测试工具放量。** 它的天花板低、投放量越大人群越泛——它只用来**测内容方向**和**测有没有被限流**。
- **禁止一次调多个变量。** 数据低于预期时先判断卡在哪一环，然后**其他不变，先改定向 → 不行再改出价 → 都试过还不行才换素材**。
- **禁止在素材还没跑满一个完整周期时就下结论。** 素材上线后要等它跑完至少一整天再依据数据优化。
- **禁止在品牌还没有心智时上品牌类工具。** 先查自己品牌词的月搜索量——量级不够说明用户还不认识你，投给不认识你的人就是白花钱。

### 工序二 · 定内容源与信息流搜索分工

**两条链路只差谁产内容**：自家账号自产，或外部合作方产。**三段各管一件事**：内容段是验证与源头（数据过关才进入下一步）；信息流段是放量（把好内容放大触达精准人群）；搜索段是卡位收割（拦截已被教育的人、把好内容前置）。

**禁止**：

- **禁止照搬任何官方给的配比。** 信息流与搜索的比例由**这个品类的用户有没有强搜索行为、搜索发生在什么时间**决定；没有强搜索行为的品类，把比重放到内容与信息流。
- **禁止窄内容配窄定向。** 正确组合是**窄内容 + 宽定向**——用内容筛人，用宽定向把池子做大。内容本就垂直、定向还很窄，池子太小会放不出去。
- **禁止在没算账之前决定投流还是招人。** "不投流就做不起来"是伪命题；做不起来的真因往往是内容不符合平台的分发逻辑和用户逻辑。**利润率撑不住投流的品，就老实走自然流。**
- **禁止在没有内容布局、没有跑出爆文之前就开搜索。** 用一条低互动的内容去卡搜索，和用一条高互动的内容去卡，效率完全不同。

### 工序三 · 判要不要叠平台放大器

**平台侧的各种资源与玩法全是可选放大器，不是必选项。** 每一项落地前先过两关：

1. **适配判断**——客单价、品类、人群、阶段、内容宽容度是否匹配；
2. **算账判断**——成本（合作费、赠品、邮寄、坑位费）能否被后端结果 cover。

> **守不住这两关，放大器只会把噪音放得更大。**

**禁止**：

- **禁止单独买一个大曝光位。** 商业化产品**组合起来效率最高**；单买一个大曝光位，这钱投得不合理——宁愿把钱省下来做内容并放大它。
- **禁止对低成本测试类资源抱过高预期。** 那类资源本质是开盲盒，有惊喜也有折损；它最大的价值是**把测试成本压到最低**。

### 工序四 · 排节奏、分预算、处理波动与衰退

**最核心的方法：从最终结果往前倒推。** 先定一个最终点目标（要电商转化就投转化类计划）；**终极目标跑不出去时往前推一步**——去投更浅层的计划（访客、互动、点击），直到无处可推。**推的次序一定由后往前，反过来会跑飞。**

**禁止**：

- **禁止把成本上涨当成"数据不好"。** 大促周期成本上涨是正常现象——流量没有增量，只是被更强势的付费方买走。**要不要加投取决于任务目标，不取决于数据好不好看。**
- **禁止在排除客观因素之前判"衰退"。** 先提价试试（能恢复就不是衰退，是出价没竞争力）→ 看预算有没有到临界点 → 看是不是做过计划调整 → 看内容有没有被审核异常。**都排除、且成本持续升、点击率持续走低、连续几天都在跌，才是真衰退。**
- **禁止在原计划上死磕。** 真衰退靠把爆款素材变形重搭，不在原计划上费劲；素材衰退（点击率明显在掉）则**保留原有的种草价值点，换封面和标题重新框**。
- **禁止在数据突然变低时立刻动手。** 先用时间维度横向比对——同样的内容最早那批的流转数据还行、近期很差，很可能是平台数据流转有周期，**再等等**。
- **禁止把有限预算平摊。** 用二八法则，把钱压到当下效率最高、流转链路最高的那条路线上。

## 接口与边界（声明）

- **适用环节**：「把成片与策划转译成投放方案并维持其效率」——换一个客户项目也会再次发生的固定环节，非一次性事务。
- **input schema**：`成片`（数组，每条含形态、封面、标题）；`策划`（生命周期阶段、链路终点、客单价、决策成本、品类搜索强度、指标，对象）；`预算总包`（数值）；`节点`（可选，字符串；平销或某个大促阶段）；`运行时数据`（可选，对象；投放跑起来后才有的点击率、互动、组件点击率、转化与消耗）。
- **output schema**：`投放方案`（内容源、信息流与搜索配比及其依据、工具配置、出价模式、MVP 阈值、节奏、可选放大器结论）；`放量与止损条件`（各写成一条可当场判定的句子）；`诊断记录`（数组，每条含现象、排查路径、结论、下一步）；`挂回的定性意图`（每个动作对应哪段策略）。**可沉淀候选（reusable_candidates）**：本品类的点击成本与阅读成本基点、验证过的定向与出价组合、能放量的素材特征、平台放大器的适配与算账结论。——**它们只是候选；够不够格真的留下、沉进哪一格、标什么成色，按 REQUIRED BACKGROUND: `tingle:banking-proven-assets` 判。**
- **写回位置**：`投放方案落点`（见 requirements 的 outputs 段），地址由项目档案登记，不自行选址。
- **规则层与项目事实**：运行时挂 **合规类目层**（判某些工具、某些形态在本类目下能不能用——部分类目不允许参加某些平台活动）与 **品牌层**（品牌既有心智决定品牌类工具能不能上）；不挂类型层。所需项目事实字段：`合规类目`、`产品品类`、`品牌`、`阶段`。
- **工具**：读飞书文档与多维表格（经开工单地址取得）、写飞书文档（登记的落点）。投放后台的数据由人提供读数，本 skill 不直接操作投放后台、不下达任何投放指令。
- **决策档**：**决策**——本环节决定钱怎么花、放到多大、什么时候停，属于对项目走向本身的判断，须由人来定，本 skill 负责把账算清、把方案备齐。**不得标自动。**
- **复核包**：投放方案本体 ＋ 配比的依据（本品类搜索行为的判断与其数据来源）＋ MVP 阈值的算法与取值来源 ＋ 每次诊断的排查路径与结论 ＋ 放量与止损条件 ＋ 未取到的数据清单。
- **升级条件（命中即停交人）**：①某个工具或玩法在本类目下的合规性不确定；②四层规则冲突；③缺关键项目事实（合规类目、产品品类、阶段任一取不到）；④产出需对外发送；⑤**任何一次实际的预算下达或放量决定**；⑥判定一个计划进入真衰退、要重搭；⑦要叠任一平台放大器；⑧拿不到本品类的成本基点、MVP 阈值只能凭经验设。

## 产出验收判据（DoD）

一次运行合格，当且仅当：

1. 信息流与搜索的配比写明了它由什么推出来（本品类的搜索行为强弱 + 数据来源），**没有照搬任何官方比例**；
2. MVP 阈值写成一条可当场判定的句子（含具体量级与它的取值来源）；未跑到阈值之前的方案里**没有任何放量动作**；
3. 出价模式写明了当前处在哪个阶段（找模型还是放量），以及为什么用这个模式；
4. 每一个投放动作都挂回一段定性意图——按 REQUIRED BACKGROUND: `tingle:keeping-metrics-anchored` 判，有孤儿指标即不合格；
5. 放量条件与止损条件各写成一条可当场判定的句子（不是"效果好就加""不行就停"）；
6. 每一次诊断都留下排查路径（先查了什么、排除了什么、结论是什么），**没有一次是直接下结论的**；
7. 引用的任何成本、转化率、阅读成本数值都标了来源与采集时间；本项目还没有基点的，明确写"需先建监控"，**不借用别的品类的值**；
8. 叠了平台放大器的，适配判断与算账判断各有一条结论。

## Quick Reference

| 情形 | 动作 |
|---|---|
| 成片就绪要投 | 先明确目的（拿流量还是卖货），再选工具 |
| 想快速测内容方向 | 用小额测试工具，**不要用它放量** |
| 前期想把内容打成爆文 | 用互动导向出价；成爆文后转点击出价 |
| 计划跑不出去 | 按序排查：时间拉满 → 去掉定向 → 改出价 → 拉高预算 → 换更浅层目标 → 最后才怀疑素材 |
| 深层计划跑不动 | 用浅层计划先帮跑人群，再由后往前推回来 |
| 成本突然上涨 | 先判断是不是大促周期的正常现象；加不加投看任务目标 |
| 数据突然变低 | 先做时间维度横向比对，可能是平台流转周期 |
| 点击率持续走低 | 素材衰退——保留种草价值点，换封面标题重新框 |
| 想开搜索 | 先确认已有内容布局与跑出来的爆文 |
| 品牌词月搜索量很低 | 不上品牌类工具 |
| 预算有限 | 二八法则，压到当下效率最高的那条线 |
| 要下达实际预算或放量 | 停，交人 |

## Common Mistakes

- **没跑出模型就放量**——钱花了没有反馈。
- **用小额测试工具放量**——天花板低、人群越投越泛。
- **照搬官方配比**——比例由品类的搜索行为决定，不由别人的经验决定。
- **窄内容配窄定向**——池子太小，放不出去。
- **一次调多个变量**——分不清是哪一项起的作用。
- **素材没跑满一个周期就换**——数据还没稳定。
- **一上来就投最深层的目标**——没有用户跑到那一层，计划必然跑飞。
- **成本一涨就判定投放出问题**——大促周期成本上涨是常态。
- **不排除客观因素就判衰退**——多数"衰退"其实是出价没竞争力。
- **在原计划上死磕**——真衰退要重搭，不是修补。
- **只看爆文数或只看单次点击成本**——有爆文没结果毫无意义。
- **心智没起来就上品牌类工具**——投给不认识你的人。

## Red Flags（出现即停，回到对应工序）

- 「数据还行，先放量试试」→ 回工序一，先看 MVP 阈值过没过。
- 「用小额工具多投点」→ 回工序一，它不用于放量。
- 「官方建议这个比例，照做」→ 回工序二，按本品类的搜索行为定。
- 「定向再收窄一点，更精准」→ 回工序二，窄内容配宽定向。
- 「先开搜索抢位置」→ 回工序二，先有内容布局与爆文。
- 「这个资源位挺好，买一个」→ 回工序三，先过适配与算账两关。
- 「这条不行了，换素材」→ 回工序四，先按序排查完再动素材。
- 「成本涨了，赶紧停」→ 回工序四，先判断是不是周期性现象。
