# 八格与字段：一条资产沉在哪、怎么描述它

> 本件是 `banking-proven-assets` 的深读件，**走到工序二（定格与定成色）时读**。
> 工序一判完了"够不够格"；这一份回答"够格的那些，各自放到哪一格、要把它描述成什么样，下一单才取得出来。"

---

## 〇、格子的设计原理

一条东西够格沉下来，取决于它能不能被单独取出来重复使用。这三条同时也是格子的收纳标准：

| 它必须 | 落到格子上的要求 |
|---|---|
| **离结果近** | 每一条都要带"它跑出过什么结果"的证据，不是凭感觉收进来的 |
| **能重复用** | 每一条都要能脱离原来那条内容被单独取出来，装到下一条上 |
| **是最小单元** | 粒度到一句话、一个镜头、一个词为止，不是整条内容、不是整套方案 |

一句话：**格子里放的不是内容，是被验证过的、能被单独取用的最小单元。**

---

## 一、八个格子

**这八个名字就是全系统的叫法，别处引用一律用这八个，不另起别名**——一旦有人管同一个格子叫别的名字，两边就各存各的，谁也取不到谁的。

| # | 格 | 放什么（最小单元） |
|---|---|---|
| 1 | **脸** | 能打的真人、模特、演员、代言身份（连同他和这个品类的关联性、还剩多少素材没用） |
| 2 | **画面** | 能打的镜头：超级效果、符号动作、实验、同框（连同怎么拍出来的分步做法） |
| 3 | **金句** | 能打的句子、框架、口播（连同框架里哪几个词位可以换） |
| 4 | **人群** | 从内容角度发现的机会人群（标签 ＋ 他们的需求集，不是后台的人口统计口径） |
| 5 | **需求** | 用户自己说出来的需求原话（连同它在榜上的位置和出现的次数） |
| 6 | **痛点** | 用户真正感受到的痛的原话（不解决就持续别扭的那种） |
| 7 | **场景** | 使用场景、购买场景、时令节点（连同可以一键替换的那个指令词） |
| 8 | **打法** | 被验证过的可复制配方：分步做法、开头公式、叠加组合、判断基点、测新结构 |

**新开一格要停下交人**——格子的划分变了，已经沉着的东西就要重新归位，这不是一个人在一次收尾里能拍的板。

---

## 二、公共字段（八格共有，缺一不沉）

| 字段 | 填什么 | 为什么缺不得 |
|---|---|---|
| **编号** | 唯一编号，供下游引用 | 下一单要能点名取用某一条 |
| **本体** | 原话／原镜头描述——**记原话，不抽象** | 抽象一层，可复用的颗粒度就没了 |
| **来自哪个客户与品类** | 它是在哪个项目、哪个品类跑出来的 | 跨项目取用时要知道它的出身，判它能不能搬 |
| **证据** | 数 ＋ 来源：跑出了什么、在哪能查到 | 没有它，这一条就是一句主张 |
| **成色** | 四档之一（见第三节） | 下一单靠它决定"拿它当结论还是当假设" |
| **挂回的意图** | 它在为哪一段意图作证 | 缺了它，取用的人不知道该在什么场合用它 |
| **时效** | 到什么时候为止，或标长效 | 去年的满分是今年的起点，过期的要重新打磨 |
| **来源素材** | 能溯回一手的链接或素材编号 | 复核的人要能核，不能只信 |
| **合规要点** | **凡有合规风险的必填**：怎么做才不越线 | 缺了它，下一个照做的人不知道自己在踩什么 |

**"合规要点"这一格填什么，由取用它的环节按它挂的那几层规则判**——本件只要求这一格在有风险时非空。**把过审要点和做法绑在一起沉下来**，下一个照做的人才不会把做法学会了、把边界丢了。

---

## 三、成色四档（一把单调的尺）

**这把尺量的只有一件事：验到什么程度。** 不量"谁能做"、不量"重不重要"。

| 档 | 判据 | 能拿它干什么 |
|---|---|---|
| **未成文** | 只在某个人脑子里，还没写成别人能读的东西 | **不入格。** 它是原料，先走工序三把它写出来 |
| **待验** | 已经写成了别人能照做的规则，但本项目还没用自己的数据验过 | 入格，**只能当测试的依据，不能当结论用** |
| **已验** | 本项目自己跑出过一次达标结果 | 可复用、可放大 |
| **可放量** | 本项目多次跑出达标结果 | 可放量，可以被自动调用 |

**三条纪律**：

1. **不跳档。** 没验过不能是"已验"；验过一次不能是"可放量"——一次分不出运气和规律。
2. **降档不是失败，是维护。** 一条"已验"的东西过了时效、或后来几次都没跑出来，就降回"待验"。**降档比留着一条名不副实的更有价值。**
3. **别人的数不能撑起任何一档。** 用别人模板上的数标出来的"已验"，是这把尺最常见的一种坏法——它看起来是三档，实际连"待验"都不到，因为连本项目的一次验证都没有。

## 四、各格另加的字段

公共字段之外，各格按自己的用法另加几格。**这几格的作用是让下一单能"取得准"，不是让记录看起来完整。**

| 格 | 另加什么 | 加它是为了 |
|---|---|---|
| **脸** | 关联性（他的特质和这个品类的哪个关键点挂钩）／还剩多少素材没用／绑死了哪个框架（换人就失效的那种）／情绪表达能力 | 选人不是选名气，是选关联；框架绑死的要记清，否则换人之后不知道为什么不灵了 |
| **画面** | 类型（超效／符号动作／实验／同框）／分步做法／过审要点／它能当外壳还是内核 | 镜头本身不可复用，可复用的是拍出它的那套步骤 |
| **金句** | 框架（可复用的那个题干）／框架里可替换的词位／它主打哪个脚本要素 | 真正稀缺的是框架，词只是往空格里填的答案 |
| **人群** | 标签集与需求集／怎么发现的／关联的需求与痛点编号 | 人群要能和需求、场景交叉组合才用得起来 |
| **需求** | 在榜上的位置／出现的次数／是视觉侧还是脚本侧、是问题型还是效果型／是不是这个品类的核心卖点 | 位置和次数是它值不值钱的量度 |
| **痛点** | 是不是从原理讲透的／这句原话是从哪采到的（评论、问答还是别处） | 讲透原理的痛点和只说现象的痛点不是一个量级 |
| **场景** | 类型（时令／使用／带入）／那个可一键替换的指令词／和别的要素组合起来效率如何 | 时令类的价值全在"能不能遍历一整年" |
| **打法** | 类型（分步做法／开头公式／叠加组合／判断基点／测新结构）／配方全文／它对应的判断基点／优先级画像 | 配方要全文写下来，摘要版下一个人照不了 |

**这些字段是最小集合，不是上限。** 某一格在实际用起来时发现还缺一格，**停下交人**——加字段和新开格子一样，改的是所有人共用的结构。

## 五、定格时的三种为难，各自怎么办

| 为难 | 怎么办 |
|---|---|
| **一条东西两格都像**（比如一个既能当开头也能当转化段的镜头） | **停，交人。** 不自己挑一个——挑错了下一单按另一格去找，取不到 |
| **它不属于这八格里任何一格** | **停，交人。** 不硬塞进最近的那一格，也不自己新开一格 |
| **它像是好几条东西粘在一起** | 回工序一重新拆，拆到每一条都能被单独取出来为止；拆完每一条各自过闸 |
